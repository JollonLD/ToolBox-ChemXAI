Data Module

The chemxai.data module provides classes and functions for loading and preprocessing molecular datasets for both graph-based and tabular machine learning models.

Overview

This module contains two main classes:

  • graph_datasets: For handling graph-based molecular data (PyTorch Geometric)
  • qm9_tabular: For handling tabular molecular data with various descriptor types

graph_datasets

Class for preparing graph-based molecular datasets with support for adding noise features for robustness testing.

def prepare_data_graph_noise(dataset_name='PCQM4', noise_type='gaussian', 
                             noise_scale=1.0, seed=42):
    """
    Prepare graph data with an additional noise feature for each node.
    Useful for testing robustness of explanations.
    
    Parameters
    ----------
    dataset_name : str, optional (default='PCQM4')
        Name of the dataset ('PCQM4' or 'QM9')
    noise_type : str, optional (default='gaussian')
        Type of noise to add:
        - 'gaussian': Normal distribution with mean=0, std=noise_scale
        - 'uniform': Uniform distribution in [-noise_scale, noise_scale]
        - 'binary': Random binary values {0, 1}
    noise_scale : float, optional (default=1.0)
        Scale/magnitude of the noise
    seed : int, optional (default=42)
        Random seed for reproducibility
        
    Returns
    --------
    NoisyGraphDataset : torch_geometric.data.InMemoryDataset
        Dataset with added noise feature. Contains an additional 
        attribute 'is_noise' (boolean mask indicating noise feature).
    
    Example
    -------
    >>> gd = graph_datasets()
    >>> noisy_data = gd.prepare_data_graph_noise(
    ...     dataset_name='QM9',
    ...     noise_type='gaussian',
    ...     noise_scale=0.5
    ... )
    >>> print(f"Number of features: {noisy_data.num_features}")
    >>> print(f"Noise feature index: {noisy_data.is_noise.nonzero()}")
    """

qm9_tabular

Class for loading and preprocessing QM9 dataset with various molecular descriptors for tabular ML models.

Initialization

from chemxai.data import qm9_tabular

qm9 = qm9_tabular()
# Automatically downloads and extracts QM9 dataset if not present

Properties

The QM9 dataset contains 15 molecular properties:

  • Rotational constants (A, B, C): GHz
  • Dipole moment (μ): Debye (D)
  • Isotropic polarizability (α): atomic units
  • HOMO energy (ϵ_HOMO): Hartree
  • LUMO energy (ϵ_LUMO): Hartree
  • Energy gap (ϵ_gap): Hartree
  • Electronic spatial extent: atomic units
  • Zero point vibrational energy: Hartree
  • Internal energy at 0K (U0): Hartree
  • Internal energy at 298.15K (U): Hartree
  • Enthalpy at 298.15K (H): Hartree
  • Free energy at 298.15K (G): Hartree
  • Heat capacity at 298.15K (Cv): cal/mol·K

Supported Descriptor Types

The class supports various molecular descriptor types:

Descriptor Description Use Case
Morgan Circular fingerprints (ECFP) General structure representation
MorganCount Morgan with occurrence counts Frequency-based features
CM Coulomb Matrix 3D geometry and charge distribution
Physicochemical 2D physicochemical descriptors Drug-like properties
3D 3D geometry-based descriptors Spatial properties
MACCS MACCS keys (166 bits) Substructure screening
Topological Daylight-style fingerprints Molecular topology
AtomPair Atom pair fingerprints Pharmacophore mapping
EState Electrotopological state indices Electronic properties
Pattern SMARTS pattern fingerprints Substructure queries
Avalon Avalon fingerprints Similarity screening
Autocorr 2D autocorrelation descriptors Structure-property relationships

get_paired_dataloaders_tabular

def get_paired_dataloaders_tabular(
    att_index=10,
    batch_size=32,
    descriptor_type='Morgan',
    list_mols=[],
    n_noise=0,
    morgan_radius=2,
    morgan_nBits=512,
    cache_descriptors=True,
    split_ratio=[0.8, 0.1, 0.1],
    seed=42
):
    """
    Create dataloaders for tabular molecular data with optional noise features.
    
    Parameters
    ----------
    att_index : int, optional (default=10)
        Index of the target property (0-14) to predict
    batch_size : int, optional (default=32)
        Batch size for dataloaders
    descriptor_type : str, optional (default='Morgan')
        Type of molecular descriptor (see table above)
    list_mols : list, optional (default=[])
        Filter molecules by number of atoms. Empty list = all molecules
    n_noise : int, optional (default=0)
        Number of random noise features to add for robustness testing
    morgan_radius : int, optional (default=2)
        Radius for Morgan fingerprints
    morgan_nBits : int, optional (default=512)
        Number of bits for fingerprint representations
    cache_descriptors : bool, optional (default=True)
        Whether to cache computed descriptors for faster reloading
    split_ratio : list of float, optional (default=[0.8, 0.1, 0.1])
        Train/validation/test split ratios
    seed : int, optional (default=42)
        Random seed for reproducibility
        
    Returns
    -------
    tuple
        If n_noise > 0:
            (train_loader, val_loader, test_loader,
             train_loader_noise, val_loader_noise, test_loader_noise, is_noise)
        If n_noise == 0:
            (train_loader, val_loader, test_loader, None, None, None, None)
            
        where is_noise is a boolean mask indicating noise feature positions
    
    Example
    -------
    >>> from chemxai.data import qm9_tabular
    >>> 
    >>> # Basic usage without noise
    >>> qm9 = qm9_tabular()
    >>> train_loader, val_loader, test_loader, *_ = qm9.get_paired_dataloaders_tabular(
    ...     att_index=7,  # Predict energy gap
    ...     batch_size=64,
    ...     descriptor_type='Morgan',
    ...     morgan_nBits=1024
    ... )
    >>> 
    >>> # With noise for robustness testing
    >>> loaders = qm9.get_paired_dataloaders_tabular(
    ...     att_index=7,
    ...     batch_size=64,
    ...     descriptor_type='Morgan',
    ...     n_noise=5  # Add 5 random noise features
    ... )
    >>> train, val, test, train_noise, val_noise, test_noise, is_noise = loaders
    >>> 
    >>> # Use the loaders in training
    >>> for batch_x, batch_y in train_loader:
    ...     # batch_x: [batch_size, n_features]
    ...     # batch_y: [batch_size, 1]
    ...     predictions = model(batch_x)
    ...     loss = criterion(predictions, batch_y)
    """

Best Practices

Descriptor Selection

  • Morgan fingerprints: Good general-purpose choice, captures circular substructures
  • Physicochemical descriptors: Best for drug-like property prediction
  • 3D descriptors: Use when geometry is important (requires 3D coordinates)
  • MACCS keys: Fast and efficient for similarity searches

Performance Optimization

  • Enable cache_descriptors=True to avoid recomputing descriptors
  • Use appropriate batch_size based on available memory
  • For large datasets, consider filtering with list_mols parameter
  • Set seed for reproducible train/val/test splits

Noise Features for Robustness Testing

  • Start with n_noise=3-5 for initial robustness tests
  • Use noise_type='gaussian' for realistic perturbations
  • Compare explanations between clean and noisy models using RobustnessEvaluator

Troubleshooting

Memory Issues

# Reduce batch size
loaders = qm9.get_paired_dataloaders_tabular(batch_size=16)

# Filter to smaller molecules
loaders = qm9.get_paired_dataloaders_tabular(list_mols=[5, 6, 7, 8, 9])

Slow Data Loading

# Enable caching
loaders = qm9.get_paired_dataloaders_tabular(cache_descriptors=True)

# First run will be slow (computing descriptors)
# Subsequent runs will be much faster

Reproducibility

# Always set seed for reproducible splits
loaders = qm9.get_paired_dataloaders_tabular(seed=42)
