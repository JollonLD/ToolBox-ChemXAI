1.2 qm9_tabular

Class for handling tabular molecular descriptors from QM9 dataset.

Supported Descriptor Types:

  • Morgan: Circular fingerprints (ECFP)
  • MorganCount: Morgan with occurrence counts
  • CM: Coulomb Matrix
  • Physicochemical: 2D physicochemical descriptors
  • 3D: 3D geometry-based descriptors
  • MACCS: MACCS keys (166 bits)
  • Topological: Daylight-style fingerprints
  • AtomPair: Atom pair fingerprints
  • EState: Electrotopological state indices
  • Pattern: SMARTS pattern fingerprints
  • Avalon: Avalon fingerprints
  • Autocorr: 2D autocorrelation descriptors
qm9_tabular.get_paired_dataloaders_tabular(att_index=10, batch_size=32, descriptor_type='Morgan', ...)
ParameterTypeDefaultDescription
att_indexint10Target property index (0-14)
batch_sizeint32Batch size for dataloaders
descriptor_typestr'Morgan'Type of molecular descriptor
list_molslist[]Filter by number of atoms
n_noiseint0Number of noise features to add
morgan_radiusint2Radius for Morgan fingerprints
morgan_nBitsint512Number of bits for fingerprints
cache_descriptorsboolTrueCache computed descriptors
split_ratiolist[0.8,0.1,0.1]Train/val/test split ratios
seedint42Random seed

Returns: tuple of DataLoaders (train, val, test, train_noise, val_noise, test_noise, is_noise)

from chemxai.data import qm9_tabular

qm9 = qm9_tabular()

# Basic usage
train, val, test, *_ = qm9.get_paired_dataloaders_tabular(
    att_index=7,  # Energy gap
    batch_size=64,
    descriptor_type='Morgan',
    morgan_nBits=2048
)

# With noise for robustness testing
result = qm9.get_paired_dataloaders_tabular(
    att_index=7,
    n_noise=5,
    descriptor_type='Morgan'
)
train, val, test, train_n, val_n, test_n, is_noise = result

2. Models Module (chemxai.models)

2.1 MLP - Multi-Layer Perceptron

MLP(input_dim, output_dim, layers, device, lr=0.001)
ParameterTypeDescription
input_dimintNumber of input features
output_dimintNumber of outputs (typically 1 for regression)
layerslist[int]Hidden layer sizes, e.g., [256, 128, 64]
devicetorch.deviceDevice ('cpu' or 'cuda')
lrfloatLearning rate for Adam optimizer

Attributes:

  • layers: nn.Sequential of all layers
  • criterion: nn.L1Loss (MAE)
  • optimizer: torch.optim.Adam
from chemxai.models import MLP
import torch

device = torch.device('cuda' if torch.cuda.is_available() else 'cpu')

model = MLP(
    input_dim=2048,  # Morgan fingerprint size
    output_dim=1,
    layers=[256, 128, 64],
    device=device,
    lr=0.001
).to(device)

# Forward pass
x = torch.randn(32, 2048).to(device)
predictions = model(x)
print(predictions.shape)  # torch.Size([32, 1])

2.2 GCN - Graph Convolutional Network

GCN(num_features, hidden_dim=256)
ParameterTypeDefaultDescription
num_featuresint-Number of node features
hidden_dimint256Hidden layer dimensions

Architecture:

  • 3 GCN layers with batch normalization
  • Global add pooling
  • 2 fully connected layers
  • Dropout (0.3) for regularization
from chemxai.models import GCN
from chemxai.data import graph_datasets

gd = graph_datasets()
dataset = gd.prepare_data_graph('QM9')

model = GCN(
    num_features=dataset[0].x.shape[1],
    hidden_dim=256
).to(device)

# Single graph prediction
data = dataset[0]
prediction = model(data.x, data.edge_index)

# Batch prediction
from torch_geometric.loader import DataLoader
loader = DataLoader(dataset, batch_size=32)
batch = next(iter(loader))
predictions = model(batch.x, batch.edge_index, batch.batch)

3. Explainers Module (chemxai.explainers)

3.1 Tabular Explainers

3.1.1 Shap

SHAP (SHapley Additive exPlanations) for tabular data using KernelExplainer.

Shap(model, background_tensor, test_tensor, device)
ParameterTypeDescription
modelnn.ModuleTrained PyTorch model
background_tensortorch.TensorBackground data for SHAP
test_tensortorch.TensorTest data to explain
devicetorch.deviceDevice for computation

Methods:

explain_local(index)

Generate local explanation for a specific instance.

Returns: list of SHAP values (one per feature)

explain_global()

Generate global feature importance across all test instances.

Returns: list of mean absolute SHAP values

from chemxai.explainers import Shap

# Get data
train_batch = next(iter(train_loader))
test_batch = next(iter(test_loader))

# Create explainer
explainer = Shap(
    model=model,
    background_tensor=train_batch[0],
    test_tensor=test_batch[0],
    device=device
)

# Local explanation for first molecule
local_shap = explainer.explain_local(index=0)
print(f"SHAP values shape: {len(local_shap)}")

# Global feature importance
global_shap = explainer.explain_global()
print(f"Most important feature: {global_shap.index(max(global_shap))}")

3.1.2 LIME

LIME (Local Interpretable Model-agnostic Explanations) for tabular data.

LIME(model, background_tensor, test_tensor, device, mode='regression')
ParameterTypeDefaultDescription
modelnn.Module-Trained model
background_tensortorch.Tensor-Training data
test_tensortorch.Tensor-Test data
devicetorch.device-Computation device
modestr'regression''regression' or 'classification'

Methods:

explain_local(index, num_features=None)

Generate LIME explanation for a specific instance.

Returns: list of feature importances

from chemxai.explainers import LIME

explainer = LIME(
    model=model,
    background_tensor=train_batch[0],
    test_tensor=test_batch[0],
    device=device,
    mode='regression'
)

# Explain first molecule
lime_values = explainer.explain_local(index=0, num_features=20)
print(f"Top features: {sorted(range(len(lime_values)), key=lambda i: abs(lime_values[i]), reverse=True)[:5]}")

3.2 Graph Explainers

3.2.1 GNNExplain

Native GNN explainer using masking to identify important nodes and edges.

GNNExplain(model, device, data, epochs, mode='regression', task_level='graph', return_type='raw')
ParameterTypeDefaultDescription
modelnn.Module-GNN model
devicetorch.device-Computation device
dataData-PyG graph data
epochsint-Training epochs for explainer
modestr'regression'Task mode
task_levelstr'graph''node' or 'graph'
return_typestr'raw'Return format

Methods:

explain(index=None)

Returns: tuple of (node_mask, edge_mask, explanation_object)

from chemxai.explainers import GNNExplain

# Create explainer for a molecule
explainer = GNNExplain(
    model=gcn_model,
    device=device,
    data=graph_data,
    epochs=100,
    mode='regression',
    task_level='graph'
)

# Get explanation
node_mask, edge_mask, explanation = explainer.explain()

# Identify most important nodes
important_nodes = torch.argsort(torch.tensor(node_mask), descending=True)[:5]
print(f"Top 5 important nodes: {important_nodes.tolist()}")

5. Evaluation Module (chemxai.evaluate)

5.1 RobustnessEvaluator

Evaluate robustness of explanations by comparing clean vs noisy models.

RobustnessEvaluator(first_model, second_model, x1_train, x1_test, x2_train, x2_test, device, model_type='graph', explainer_type='shap_local', mol_index=0, atom_index=0)
ParameterTypeDescription
first_modelnn.ModuleFirst model (typically clean)
second_modelnn.ModuleSecond model (typically with noise)
x1_trainDataLoaderTraining data for first model
x1_testDataLoaderTest data for first model
x2_trainDataLoaderTraining data for second model
x2_testDataLoaderTest data for second model
devicetorch.deviceComputation device
model_typestr'tabular' or 'graph'
explainer_typestrType of explainer to use

Explainer Types:

  • 'shap_local': Local SHAP for tabular data
  • 'shap_global': Global SHAP for tabular data
  • 'lime': LIME for tabular data
  • 'gnn_explainer': GNNExplainer for graphs
  • 'graph_shap': GraphShap
  • 'graph_lime': GraphLIME
  • 'node_graph_shap': NodeGraphShap
  • 'node_graph_lime': NodeGrapLIME

Methods:

get_metrics()

Compute robustness metrics between two models' explanations.

Returns: tuple of (similarities, l1_differences, l2_differences, spearman_correlations, figures)

from chemxai.evaluate import RobustnessEvaluator
import numpy as np

# Get paired dataloaders (clean and noisy)
result = qm9.get_paired_dataloaders_tabular(
    att_index=7,
    batch_size=32,
    n_noise=3
)
train, val, test, train_n, val_n, test_n, is_noise = result

# Train two models (one on clean, one on noisy data)
# model_clean = ... (trained on train)
# model_noise = ... (trained on train_n)

# Create evaluator
evaluator = RobustnessEvaluator(
    first_model=model_clean,
    second_model=model_noise,
    x1_train=train,
    x1_test=test,
    x2_train=train_n,
    x2_test=test_n,
    device=device,
    model_type='tabular',
    explainer_type='shap_local'
)

# Compute metrics
sims, l1, l2, spearman, figs = evaluator.get_metrics()

# Analyze results
print(f"Mean cosine similarity: {np.mean(sims):.3f}")
print(f"Mean L1 difference: {np.mean(l1):.3f}")
print(f"Mean Spearman correlation: {np.mean(spearman):.3f}")

# Figures are saved to 'graphs/' directory

7. Complete Workflow Example

"""
Complete ChemXAI Workflow Example
Train models, generate explanations, evaluate robustness
"""

import torch
from chemxai.data import qm9_tabular
from chemxai.models import MLP
from chemxai.train import train_mlp_qm9
from chemxai.explainers import Shap
from chemxai.evaluate import RobustnessEvaluator
from chemxai.plots import horizontal_bar_plot
import numpy as np

# ============================================
# 1. SETUP
# ============================================
device = torch.device('cuda' if torch.cuda.is_available() else 'cpu')
print(f"Using device: {device}")

# ============================================
# 2. PREPARE DATA
# ============================================
qm9 = qm9_tabular()

# Get clean and noisy dataloaders
result = qm9.get_paired_dataloaders_tabular(
    att_index=7,  # Energy gap
    batch_size=64,
    descriptor_type='Morgan',
    morgan_nBits=2048,
    n_noise=3,  # Add 3 noise features
    seed=42
)
train, val, test, train_n, val_n, test_n, is_noise = result

print(f"Training samples: {len(train.dataset)}")
print(f"Feature dimension: {train.dataset[0][0].shape[0]}")
print(f"Noise features at indices: {is_noise.nonzero()[0].tolist()}")

# ============================================
# 3. TRAIN MODELS
# ============================================

# Train clean model
print("\n=== Training Clean Model ===")
history_clean = train_mlp_qm9(
    att_index=7,
    epochs=50,
    layers=[256, 128, 64],
    learning_rate=0.001,
    batch_size=64,
    descriptor_type='Morgan',
    morgan_nBits=2048,
    n_noise=0,
    layer_name='clean'
)

# Train noisy model
print("\n=== Training Noisy Model ===")
history_noise = train_mlp_qm9(
    att_index=7,
    epochs=50,
    layers=[256, 128, 64],
    learning_rate=0.001,
    batch_size=64,
    descriptor_type='Morgan',
    morgan_nBits=2048,
    n_noise=3,
    layer_name='noisy'
)

# ============================================
# 4. LOAD TRAINED MODELS
# ============================================
input_dim = 2048
model_clean = MLP(input_dim, 1, [256, 128, 64], device).to(device)
model_clean.load_state_dict(torch.load('models/mlp_qm9_Morgan_att7_clean.pth'))
model_clean.eval()

model_noise = MLP(input_dim+3, 1, [256, 128, 64], device).to(device)
model_noise.load_state_dict(torch.load('models/mlp_qm9_noise_Morgan_att7.pth'))
model_noise.eval()

# ============================================
# 5. GENERATE EXPLANATIONS
# ============================================

# Get test batches
test_batch_clean = next(iter(test))
test_batch_noise = next(iter(test_n))
train_batch_clean = next(iter(train))
train_batch_noise = next(iter(train_n))

# Create SHAP explainers
print("\n=== Creating SHAP Explainers ===")
explainer_clean = Shap(
    model=model_clean,
    background_tensor=train_batch_clean[0],
    test_tensor=test_batch_clean[0],
    device=device
)

explainer_noise = Shap(
    model=model_noise,
    background_tensor=train_batch_noise[0],
    test_tensor=test_batch_noise[0],
    device=device
)

# Get local explanations for first molecule
shap_clean = explainer_clean.explain_local(index=0)
shap_noise = explainer_noise.explain_local(index=0)

print(f"SHAP values length (clean): {len(shap_clean)}")
print(f"SHAP values length (noise): {len(shap_noise)}")

# ============================================
# 6. VISUALIZE EXPLANATIONS
# ============================================

# Plot clean model explanation
fig, ax = horizontal_bar_plot(
    values=shap_clean,
    title="Feature Importance (Clean Model)",
    max_features=30,
    save_path='explanations',
    filename='clean_model_shap.png'
)

# Plot noisy model explanation
fig, ax = horizontal_bar_plot(
    values=shap_noise[:input_dim],  # Exclude noise features from visualization
    title="Feature Importance (Noisy Model)",
    max_features=30,
    save_path='explanations',
    filename='noisy_model_shap.png'
)

# ============================================
# 7. EVALUATE ROBUSTNESS
# ============================================

print("\n=== Evaluating Robustness ===")
evaluator = RobustnessEvaluator(
    first_model=model_clean,
    second_model=model_noise,
    x1_train=train,
    x1_test=test,
    x2_train=train_n,
    x2_test=test_n,
    device=device,
    model_type='tabular',
    explainer_type='shap_local'
)

# Compute robustness metrics
sims, l1_diffs, l2_diffs, spearman_corrs, figs = evaluator.get_metrics()

# ============================================
# 8. ANALYZE RESULTS
# ============================================

print("\n=== Robustness Analysis Results ===")
print(f"Cosine Similarity:")
print(f"  Mean: {np.mean(sims):.3f}")
print(f"  Std:  {np.std(sims):.3f}")
print(f"  Min:  {np.min(sims):.3f}")
print(f"  Max:  {np.max(sims):.3f}")

print(f"\nL1 Distance:")
print(f"  Mean: {np.mean(l1_diffs):.3f}")
print(f"  Std:  {np.std(l1_diffs):.3f}")

print(f"\nSpearman Correlation:")
print(f"  Mean: {np.mean(spearman_corrs):.3f}")
print(f"  Std:  {np.std(spearman_corrs):.3f}")

# Identify most stable features
global_clean = explainer_clean.explain_global()
global_noise = explainer_noise.explain_global()

# Top 10 features by global importance
top_features_clean = sorted(range(len(global_clean)), 
                           key=lambda i: abs(global_clean[i]), 
                           reverse=True)[:10]

print(f"\nTop 10 Most Important Features (Clean Model):")
for rank, idx in enumerate(top_features_clean, 1):
    print(f"  {rank}. Feature {idx}: {global_clean[idx]:.4f}")

print("\n=== Analysis Complete ===")
print("Plots saved to 'graphs/' directory")
print("Explanations saved to 'explanations/' directory")
