chemxai.models¶

Neural network architectures for molecular property prediction. Includes implementations for both tabular descriptors and graph-structured molecular data.

MLP¶

class chemxai.models.MLP(input_dim, output_dim, layers, device, lr=0.001)

Multi-layer perceptron for molecular property regression. Uses L1Loss (MAE) and includes integrated optimizer.

Parameters:

  • input_dim (int) – Dimensionality of input features (e.g., 2048 for Morgan fingerprints)
  • output_dim (int) – Output dimensionality. Default: 1 for regression
  • layers (list of int) – Hidden layer dimensions. Example: [256, 128, 64] creates 3 hidden layers
  • device (torch.device or str) – Device for model and tensors ('cuda' or 'cpu')
  • lr (float) – Learning rate for Adam optimizer. Default: 0.001

Shape:

  • Input: (batch_size, input_dim)
  • Output: (batch_size, output_dim)

Methods:

forward(x)

Defines the forward pass computation.

Parameters:

  • x (torch.Tensor) – Input tensor of shape (batch_size, input_dim)

Returns: torch.Tensor – Output predictions of shape (batch_size, output_dim)

Architecture Details:

The network structure follows this pattern:

Input → [Linear → ReLU] × len(layers) → Linear → Output

Final layer uses Linear transformation without activation for regression. Loss function is L1Loss (MAE), optimizer is Adam integrated in the class.

Attributes:

  • layers (nn.Sequential) – Stacked linear + ReLU layers
  • criterion (nn.L1Loss) – Mean Absolute Error loss function
  • optimizer (torch.optim.Adam) – Adam optimizer with specified learning rate
  • device (torch.device) – Device where model resides

Example:

import torch
from chemxai.models import MLP

# Setup device
device = torch.device('cuda' if torch.cuda.is_available() else 'cpu')

# Create MLP for 2048-dim Morgan fingerprints
model = MLP(
    input_dim=2048,
    output_dim=1,
    layers=[512, 256, 128],  # 3 hidden layers
    device=device,
    lr=0.001
)

# Forward pass
batch_size = 32
x = torch.randn(batch_size, 2048).to(device)
output = model(x)
print(output.shape)  # torch.Size([32, 1])

# Training loop (optimizer and criterion already in model)
targets = torch.randn(batch_size, 1).to(device)

model.train()
for epoch in range(100):
    model.optimizer.zero_grad()
    predictions = model(x)
    loss = model.criterion(predictions, targets)
    loss.backward()
    model.optimizer.step()
    
    if epoch % 10 == 0:
        print(f"Epoch {epoch}, Loss: {loss.item():.4f}")

# Inference
model.eval()
with torch.no_grad():
    test_features = torch.randn(10, 2048).to(device)
    predictions = model(test_features)
    print(f"Predictions: {predictions.squeeze()}")

Architecture Variants:

  • Shallow network: layers=[256] – Fast, works for simple relationships
  • Deep network: layers=[512, 512, 256, 128] – Better for complex patterns, risk of overfitting
  • Bottleneck: layers=[256, 64, 256] – Compression in middle layers for feature learning
  • Pyramid: layers=[512, 256, 128, 64] – Gradual dimension reduction

GCN¶

class chemxai.models.GCN(num_features, hidden_dim=256)

Graph Convolutional Network for molecular graph regression using PyTorch Geometric.

Parameters:

  • num_features (int) – Dimensionality of node features (typically 11 for QM9: atom type one-hot encoding)
  • hidden_dim (int) – Hidden layer dimensionality for all graph convolutions. Default: 256

Architecture:

GCNConv(num_features → hidden_dim) → BatchNorm1d → ReLU
GCNConv(hidden_dim → hidden_dim) → BatchNorm1d → ReLU
GCNConv(hidden_dim → hidden_dim) → BatchNorm1d → ReLU
Global Add Pooling
Linear(hidden_dim → hidden_dim) → ReLU → Dropout(0.3)
Linear(hidden_dim → 1)

Key Components:

  • 3 GCN Layers: Each with batch normalization for stable training
  • Global Add Pooling: Sums node features to create graph-level representation
  • Dropout (0.3): Applied before final layer to prevent overfitting
  • Batch Inference: Handles variable-sized graphs via batch parameter

Methods:

forward(x, edge_index, batch)

Performs forward pass on a batch of molecular graphs.

Parameters:

  • x (torch.Tensor) – Node feature matrix of shape (num_nodes, num_node_features)
  • edge_index (torch.Tensor) – Graph connectivity in COO format, shape (2, num_edges)
  • batch (torch.Tensor) – Batch vector assigning each node to a graph, shape (num_nodes,)

Returns: torch.Tensor – Graph-level predictions of shape (batch_size, 1)

Graph Representation:

The GCN processes molecular graphs where:

  • Nodes represent atoms with features like atomic number, chirality, hybridization
  • Edges represent chemical bonds (covalent connections)
  • Global pooling aggregates node representations into a single graph-level vector

Example:

import torch
from torch_geometric.data import Data, Batch
from chemxai.models import GCN

# Create GCN model with default hidden_dim=256

# Example: Single molecule with 5 atoms

edge_index = torch.tensor([
    [0, 1, 1, 2, 2, 3, 3, 4],  # source nodes
    [1, 0, 2, 1, 3, 2, 4, 3]   # target nodes

# Create PyG Data object
mol_data = Data(x=x, edge_index=edge_index)

# Batch multiple molecules
batch_data = Batch.from_data_list([mol_data, mol_data, mol_data])

# Forward pass
output = model(batch_data.x, batch_data.edge_index, batch_data.batch)
print(output.shape)  # torch.Size([3, 1])

GCN Convolution Layer:

The graph convolution operation aggregates information from neighboring nodes:

h_i^(l+1) = σ(Σ_{j∈N(i)} (1/√(d_i·d_j)) · W^(l) · h_j^(l))

where:

  • h_i^(l) is the feature vector of node i at layer l
  • N(i) is the set of neighbors of node i
  • d_i, d_j are node degrees
  • W^(l) is the learnable weight matrix
  • σ is the activation function (ReLU)

Model Selection Guide¶

Aspect MLP GCN
Input Format Fixed-size descriptor vectors Variable-size molecular graphs
Structural Information Implicit (encoded in descriptors) Explicit (graph connectivity)
Permutation Invariance Descriptor-dependent Yes (graph isomorphism)
Training Speed Fast (dense operations) Medium (sparse operations)
Memory Usage Fixed per molecule Scales with molecule size
Interpretability Feature importance analysis Atom/bond importance maps
Best For Large datasets, quick experiments Small datasets, structural insights
Typical Accuracy Good (depends on descriptors) Better (learns representations)

Usage Recommendations¶

MLP Guidelines¶

  • Architecture: Start with 2-3 hidden layers. Add depth only if validation performance improves.
  • Hidden dimensions: Common pattern: [2-4x input_dim, ..., input_dim/2]. Example for 2048-dim input: [512, 256, 128]
  • Dropout: Use 0.2-0.5 to prevent overfitting. Higher values for smaller datasets.
  • Activation: ReLU is the default choice. Try ELU for deeper networks (>5 layers).
  • Batch normalization: Included by default, improves training stability and speed.
  • Optimizer: Adam with lr=0.001 works well. Reduce to 0.0001 for fine-tuning.

GCN Guidelines¶

  • Hidden dimensions: 64-128 is sufficient for most molecular tasks. QM9 uses 64.
  • Number of layers: 2-3 GCN layers capture local chemistry. More layers aggregate larger neighborhoods.
  • Pooling: Global mean pooling is default. Try global max pooling for specific tasks.
  • Node features: Use atom type, degree, formal charge, hybridization, aromaticity at minimum.
  • Edge features: Consider bond type (single/double/triple) for more expressive models.
  • Batch size: Smaller batches (16-64) due to variable graph sizes and memory constraints.
  • Optimizer: Adam with lr=0.01 and weight_decay=5e-4 for L2 regularization.

Advanced Usage¶

Transfer Learning¶

# Pre-train on large dataset
model = MLP(input_dim=2048, hidden_dims=[512, 256], output_dim=1)
# ... train on 100k molecules ...

# Fine-tune on smaller target dataset
for param in model.parameters():
    param.requires_grad = False  # Freeze feature extractor
model.fc_out.requires_grad = True   # Unfreeze output layer

optimizer = torch.optim.Adam(
    filter(lambda p: p.requires_grad, model.parameters()),
    lr=0.0001
)
# ... train on 1k target molecules ...

Ensemble Predictions¶

# Train multiple models with different initializations
models = []
for seed in [42, 123, 456, 789, 999]:
    torch.manual_seed(seed)
    model = GCN(num_node_features=11, hidden_dim=64)
    # ... train model ...
    models.append(model)

# Ensemble prediction
with torch.no_grad():
    predictions = torch.stack([m(x, edge_index, batch) for m in models])
    mean_pred = predictions.mean(dim=0)
    std_pred = predictions.std(dim=0)  # Uncertainty estimate

Notes¶

  • Both models are compatible with standard PyTorch training loops and utilities
  • GCN requires PyTorch Geometric to be installed: pip install torch-geometric
  • For multi-task learning, set output_dim to number of tasks and use appropriate loss functions
  • Models automatically move computations to GPU when inputs are on GPU devices
