Models Module - 100% Code Coverage¶

Overview¶

The Models Module provides neural network architectures for molecular property prediction: MLP for tabular descriptors and GCN for molecular graphs.

MLP - Multi-Layer Perceptron¶

Feedforward neural network for tabular molecular descriptors (Morgan fingerprints, Coulomb Matrix, etc.).

Architecture¶

  • Input layer matching descriptor dimensionality
  • Configurable hidden layers with ReLU activation
  • Output layer for regression
  • Loss: L1Loss (Mean Absolute Error)
  • Optimizer: Adam

__init__(input_dim, output_dim, layers, device, lr=0.001)¶

Parameters:

  • input_dim (int): Number of input features (e.g., 512 for Morgan, 1826 for CM)
  • output_dim (int): Number of outputs (typically 1 for property prediction)
  • layers (list): Hidden layer dimensions, e.g., [64, 32] or [128, 64, 32]
  • device (torch.device): CPU or CUDA device
  • lr (float): Learning rate. Default: 0.001

forward(x)¶

Forward pass through network.

Parameters: x (torch.Tensor): Input [batch_size, input_dim]

Returns: torch.Tensor: Predictions [batch_size, output_dim]

Usage Example¶

from chemxai.models import MLP
import torch

device = torch.device('cuda' if torch.cuda.is_available() else 'cpu')
model = MLP(input_dim=512, output_dim=1, layers=[64, 32], device=device, lr=0.001)

# Training
model.train()
for features, targets in train_loader:
    features, targets = features.to(device), targets.to(device)
    model.optimizer.zero_grad()
    predictions = model(features)
    loss = model.criterion(predictions, targets)
    loss.backward()
    model.optimizer.step()

GCN - Graph Convolutional Network¶

Graph neural network for molecular graph representations.

Architecture¶

  • 3 GCNConv layers:
    • Layer 1: num_features → hidden_dim
    • Layer 2: hidden_dim → hidden_dim
    • Layer 3: hidden_dim → hidden_dim
  • Batch Normalization after each conv layer
  • Global add pooling for graph-level representation
  • 2 FC layers: hidden_dim → hidden_dim//2 → 1
  • Dropout: p=0.3 for regularization

__init__(num_features, hidden_dim=256)¶

Parameters:

  • num_features (int): Number of node features
    • QM9: 11 features (atom type, chirality, degree, etc.)
    • PCQM4Mv2: 9 features
  • hidden_dim (int): Hidden layer dimension. Default: 256. Typical: 128, 256, 512

forward(x, edge_index, batch=None)¶

Forward pass through graph network.

Parameters:

  • x (torch.Tensor): Node features [num_nodes, num_features]
  • edge_index (torch.LongTensor): Edge connectivity [2, num_edges] in COO format
  • batch (torch.LongTensor, optional): Batch assignment vector [num_nodes]. If None, single graph assumed.

Returns: torch.Tensor: Graph-level predictions [batch_size, 1]

Usage Example¶

from chemxai.models import GCN
from chemxai.data import graph_datasets
import torch
import torch.nn as nn

device = torch.device('cuda' if torch.cuda.is_available() else 'cpu')

# Load data
graph_data = graph_datasets()
train_loader, val_loader, test_loader, *_ = graph_data.get_paired_dataloaders(
    dataset_name='QM9', batch_size=32
)

# Get num_features from data
sample = next(iter(train_loader))
model = GCN(num_features=sample.x.size(1), hidden_dim=256).to(device)

# Training
optimizer = torch.optim.Adam(model.parameters(), lr=0.001)
criterion = nn.MSELoss()

model.train()
for batch in train_loader:
    batch = batch.to(device)
    optimizer.zero_grad()
    predictions = model(batch.x, batch.edge_index, batch.batch)
    target = batch.y[:, 7].view(-1, 1)  # Property 7 (HOMO-LUMO gap)
    loss = criterion(predictions, target)
    loss.backward()
    optimizer.step()

Best Practices¶

For MLP¶

  • Layer sizes: Use decreasing dimensions [128, 64, 32]
  • Learning rate: Start 1e-3, reduce if unstable
  • Descriptors: Normalize with StandardScaler
  • Overfitting: Add dropout if val loss increases

For GCN¶

  • Hidden dim: 256 default; increase for larger datasets
  • Batch size: Use 16-32 for graph data (memory)
  • Dropout: Model has 0.3; adjust if needed
  • Pooling: Global add works well; try mean for other tasks
