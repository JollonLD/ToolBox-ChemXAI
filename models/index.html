Models Module¶

Overview¶

The Models Module provides neural network architectures for molecular property prediction, including both tabular (MLP) and graph-based (GCN) models.

MLP (Multi-Layer Perceptron)¶

Feedforward neural network for tabular molecular descriptors.

Initialization¶

from chemxai.models import MLP

model = MLP(
    input_dim=512,      # Number of input features
    output_dim=1,       # Number of outputs (regression: 1)
    layers=[128, 64],   # Hidden layer dimensions
    device=device,
    lr=0.001           # Learning rate
)

Parameters¶

  • input_dim (int): Dimension of input features
  • output_dim (int): Dimension of output
  • layers (list): List of hidden layer dimensions
  • device (torch.device): Device for computation (CPU/GPU)
  • lr (float): Learning rate for Adam optimizer. Default: 0.001

Architecture¶

  • Fully connected layers with ReLU activation
  • L1 Loss (MAE) for regression
  • Adam optimizer

GCN (Graph Convolutional Network)¶

Graph neural network for molecular graphs using GCN convolutions.

Initialization¶

from chemxai.models import GCN

model = GCN(
    num_features=11,    # Number of node features
    hidden_dim=256      # Hidden dimension
)

Parameters¶

  • num_features (int): Number of input node features
  • hidden_dim (int): Dimension of hidden layers. Default: 256

Architecture¶

  • 3 GCN convolutional layers with batch normalization
  • Global add pooling for graph-level predictions
  • 2 fully connected layers with dropout (0.3)
  • ReLU activation functions

Usage Example¶

import torch
from chemxai.models import MLP, GCN

device = torch.device('cuda' if torch.cuda.is_available() else 'cpu')

# MLP for tabular data
mlp_model = MLP(input_dim=512, output_dim=1, layers=[128, 64], device=device)
output = mlp_model(tabular_features)

# GCN for molecular graphs
gcn_model = GCN(num_features=11, hidden_dim=256).to(device)
output = gcn_model(data.x, data.edge_index, data.batch)
