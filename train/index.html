Training Module¶

Overview¶

The Training Module provides functions to train MLP and GCN models on QM9 molecular datasets with comprehensive logging and checkpointing.

train_mlp_qm9()¶

Train a Multi-Layer Perceptron on QM9 dataset using molecular descriptors.

Parameters¶

  • att_index (int): Index of QM9 property to predict (0-18). Default: 10
  • epochs (int): Number of training epochs. Default: 10
  • layers (list): Hidden layer dimensions. Default: [64, 32]
  • learning_rate (float): Learning rate. Default: 1e-3
  • batch_size (int): Batch size. Default: 32
  • descriptor_type (str): Type of molecular descriptor. Default: 'Morgan'

train_gcn_qm9()¶

Train a Graph Convolutional Network on QM9 molecular graphs.

Parameters¶

  • att_index (int): Index of QM9 property to predict. Default: 7
  • epochs (int): Number of training epochs. Default: 100
  • hidden_dim (int): Hidden dimension for GCN. Default: 256
  • learning_rate (float): Learning rate. Default: 1e-3
  • batch_size (int): Batch size. Default: 32

Usage Example¶

from chemxai.train import train_mlp_qm9, train_gcn_qm9

# Train MLP
history = train_mlp_qm9(att_index=7, epochs=50, layers=[128, 64])

# Train GCN
results = train_gcn_qm9(att_index=7, epochs=100, hidden_dim=256)
