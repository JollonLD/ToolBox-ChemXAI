Training Module

Overview

The Training module (train.py) provides comprehensive training functions for both MLP (tabular) and GCN (graph) models on molecular datasets. It includes automatic logging, model saving, early stopping, and support for noisy data augmentation.

Functions

setup_logging()

Configure logging to file and console with timestamps.

from chemxai.train import setup_logging

log_file = setup_logging(log_dir="logs")

Parameters:

  • log_dir (str): Directory to save log files (default: "logs")

Returns:

  • str: Path to the created log file

train_mlp_qm9()

Train an MLP model on QM9 dataset using molecular descriptors.

from chemxai.train import train_mlp_qm9

history = train_mlp_qm9(
    att_index=10,
    epochs=100,
    layers=[256, 128, 64],
    learning_rate=1e-3,
    batch_size=32,
    descriptor_type='Morgan',
    morgan_radius=3,
    morgan_nBits=512
)

Parameters:

Parameter Type Default Description
att_index int 10 Index of the target property (0-18 for QM9)
epochs int 10 Number of training epochs
layers list [64, 32] Hidden layer dimensions
learning_rate float 1e-3 Learning rate for optimizer
batch_size int 32 Batch size for training
n_noise int 3 Number of noise features to add
descriptor_type str 'Morgan' Type of molecular descriptor (see Data Module)
cache_descriptors bool True Whether to cache computed descriptors
num_workers int 4 Number of data loading workers
morgan_radius int 2 Radius for Morgan fingerprints
morgan_nBits int 512 Number of bits for Morgan fingerprints
log_dir str "logs" Directory for saving logs
layer_name str 'medium' Name identifier for the model architecture

Supported Descriptor Types:

  • Morgan: Circular fingerprints (ECFP)
  • MACCS: MACCS keys (166 bits)
  • RDKit2D: 2D RDKit descriptors
  • RDKit2DNormalized: Normalized 2D descriptors
  • AllChem2D: All 2D chemistry descriptors
  • Avalon: Avalon fingerprints
  • AtomPair: Atom pair fingerprints
  • Torsion: Topological torsion fingerprints
  • RDKitFPBits: RDKit fingerprint bits
  • MorganFeatures: Morgan fingerprints with features
  • LayeredFingerprint: Layered fingerprints
  • PatternFingerprint: Pattern-based fingerprints

Returns:

  • list: Training history as list of tuples (epoch, train_loss, val_loss, test_loss)

Output Files:

  • Model checkpoint: models/mlp_att{att_index}_{descriptor_type}_{layer_name}.pth
  • Training log: logs/mlp_att{att_index}_{descriptor_type}_{timestamp}.log
  • Training history: models/mlp_att{att_index}_{descriptor_type}_{layer_name}_history.json

train_gcn_qm9()

Train a Graph Convolutional Network on QM9 molecular graphs.

from chemxai.train import train_gcn_qm9

history = train_gcn_qm9(
    att_index=10,
    epochs=100,
    hidden_channels=64,
    num_layers=3,
    learning_rate=1e-3,
    batch_size=32
)

Parameters:

Parameter Type Default Description
att_index int 10 Index of the target property
epochs int 10 Number of training epochs
hidden_channels int 64 Hidden dimension size
num_layers int 3 Number of GCN layers
learning_rate float 1e-3 Learning rate
batch_size int 32 Batch size
n_noise int 3 Number of noise features
dropout float 0.2 Dropout rate
num_workers int 4 Number of data workers
log_dir str "logs" Logging directory

Returns:

  • list: Training history as list of tuples (epoch, train_loss, val_loss, test_loss)

Output Files:

  • Model checkpoint: models/gcn_att{att_index}_h{hidden_channels}_l{num_layers}.pth
  • Training log: logs/gcn_att{att_index}_{timestamp}.log
  • Training history: models/gcn_att{att_index}_h{hidden_channels}_l{num_layers}_history.json

Usage Examples

Complete MLP Training Workflow

import torch
from chemxai.train import setup_logging, train_mlp_qm9

# Setup logging
log_file = setup_logging(log_dir="training_logs")

# Train model with Morgan fingerprints
history = train_mlp_qm9(
    att_index=7,  # HOMO property
    epochs=150,
    layers=[512, 256, 128, 64],
    learning_rate=5e-4,
    batch_size=64,
    descriptor_type='Morgan',
    morgan_radius=3,
    morgan_nBits=1024,
    n_noise=5,
    layer_name='large'
)

# Access training history
for epoch, train_loss, val_loss, test_loss in history:
    print(f"Epoch {epoch}: Train={{train_loss:.4f}, Val={{val_loss:.4f}, Test={{test_loss:.4f}")

Complete GCN Training Workflow

from chemxai.train import train_gcn_qm9

# Train GCN model
history = train_gcn_qm9(
    att_index=7,  # HOMO property
    epochs=200,
    hidden_channels=128,
    num_layers=4,
    learning_rate=1e-3,
    batch_size=64,
    dropout=0.3,
    n_noise=0  # No noise features for GCN
)

Comparing Different Descriptors

# Train with different descriptor types
descriptors = ['Morgan', 'MACCS', 'RDKit2D', 'Avalon']
results = {}

for desc in descriptors:
    print(f"Training with {desc} descriptors...")
    history = train_mlp_qm9(
        att_index=7,
        epochs=100,
        descriptor_type=desc,
        layer_name=desc.lower()
    )
    results[desc] = history

Technical Details

Automatic Model Saving

  • Models are automatically saved after each epoch
  • Best model (lowest validation loss) is preserved
  • Model state includes: weights, optimizer state, epoch, losses

Logging System

  • Console logging: Real-time progress updates
  • File logging: Detailed logs with timestamps
  • Metrics tracked: Train/validation/test losses per epoch
  • Training info: Hyperparameters, data statistics, timing

Early Stopping

  • Monitors validation loss
  • Saves best model checkpoint
  • Continues training for full epoch count

Data Augmentation

  • Noise features: Random features added for robustness testing
  • Noisy datasets: Separate dataloaders with perturbed features
  • Purpose: Test explanation stability and model robustness

Device Management

  • Automatic GPU detection
  • Fallback to CPU if CUDA unavailable
  • Efficient tensor transfers between devices

Performance Optimization

  • Descriptor caching: Computed descriptors saved to disk
  • Parallel data loading: Multi-worker dataloaders
  • Batch processing: Efficient GPU utilization

Best Practices

Choosing Hyperparameters

  • Learning rate: Start with 1e-3, reduce if loss plateaus
  • Batch size: 32-64 for most cases, larger for more stable gradients
  • Layers (MLP): Start with [256, 128, 64], adjust based on descriptor size
  • Hidden channels (GCN): 64-128 for most molecular properties
  • Epochs: 100-200, monitor validation loss for convergence

Descriptor Selection

  • Morgan: Best for general molecular property prediction
  • MACCS: Good for similarity-based tasks, smaller feature space
  • RDKit2D: Interpretable physicochemical properties
  • Avalon: Good for substructure-based predictions

Computational Resources

  • Use GPU for faster training (10-50x speedup)
  • Enable descriptor caching to save computation time
  • Adjust num_workers based on available CPU cores
  • Monitor memory usage with large batch sizes
