chemxai.train¶

Training pipelines for molecular property prediction models. Provides high-level interfaces for training MLPs on tabular descriptors and GCNs on molecular graphs, with support for adversarial robustness and various preprocessing options.

train_mlp_qm9¶

function chemxai.train.train_mlp_qm9(att_index=10, epochs=10, layers=[64, 32], learning_rate=1e-3, batch_size=32, n_noise=3, descriptor_type='Morgan', cache_descriptors=True, num_workers=4, morgan_radius=2, morgan_nBits=512, log_dir="logs", layer_name='medium')

Trains a multi-layer perceptron on QM9 molecular descriptors for property prediction with automatic logging.

Parameters:

att_index (int)
Target property index from QM9 dataset (0-14). Default: 10 (G - free energy at 298.15K)
epochs (int)
Number of training epochs. Default: 10
layers (list of int)
Hidden layer architecture specification. Each element defines the number of neurons in that layer.
Default: [64, 32]
learning_rate (float)
Initial learning rate for Adam optimizer. Default: 1e-3
batch_size (int)
Mini-batch size for training. Default: 32
n_noise (int)
Number of noise features to add for noise detection experiments. Default: 3
descriptor_type (str)
Molecular descriptor type to generate. Default: 'Morgan'. Options:
  • 'CM' – Coulomb Matrix
  • 'Morgan' – Morgan fingerprints (ECFP, circular)
  • 'MorganCount' – Morgan fingerprints with occurrence counts
  • 'Physicochemical' – 2D physicochemical descriptors
  • '3D' – 3D geometric descriptors
  • 'MACCS' – MACCS structural keys (166-bit)
  • 'Topological' – Topological fingerprints
  • 'AtomPair' – Atom pair fingerprints
  • 'EState' – E-State indices
  • 'Pattern' – Pattern fingerprints
  • 'Avalon' – Avalon fingerprints
  • 'Autocorr' – 2D autocorrelation descriptors
cache_descriptors (bool)
Whether to cache computed descriptors for faster loading. Default: True
num_workers (int)
Number of workers for data loading. Default: 4
morgan_radius (int)
Radius for Morgan fingerprints. Default: 2
morgan_nBits (int)
Number of bits for Morgan fingerprints. Default: 512
log_dir (str)
Directory to save detailed training logs. Default: "logs"
layer_name (str)
Name identifier for the layer configuration. Default: 'medium'

Returns:

  • list – List of tuples (epoch, train_loss, val_loss) for each training epoch

Training Process:

  1. Load QM9 dataset and compute specified molecular descriptors
  2. Add n_noise noise features if n_noise > 0
  3. Split data: 80% train, 10% validation, 10% test
  4. Normalize features using StandardScaler (fit on train, transform all)
  5. Initialize MLP with specified architecture and device
  6. Train using integrated optimizer and L1Loss (MAE)
  7. Save model checkpoint and detailed logs to log_dir
  8. Return training history (losses per epoch)

Example - Basic Training:

from chemxai.train import train_mlp_qm9

# Train MLP for HOMO-LUMO gap prediction
model, test_loader, scaler = train_mlp_qm9(
    att_index=4,                    # gap property
    epochs=100,
    layers=[256, 512, 256],         # 3 hidden layers
    learning_rate=0.001,
    batch_size=64,
    descriptor='ECFPs',
    noise_level=0.0,
    attack_method=None,
    att_train_size=0,
    custom_att=None,
    random_seed=42
)

# Evaluate on test set
import torch
model.eval()
test_loss = 0
predictions_list = []
targets_list = []

with torch.no_grad():
    for features, targets in test_loader:
        features = features.to(model.device)
        predictions = model(features)
        predictions_list.append(predictions.cpu())
        targets_list.append(targets)

predictions = torch.cat(predictions_list).numpy()
targets = torch.cat(targets_list).numpy()

# Denormalize predictions
predictions_original = scaler.inverse_transform(predictions)
targets_original = scaler.inverse_transform(targets.reshape(-1, 1))

# Compute metrics
from sklearn.metrics import mean_absolute_error, r2_score
mae = mean_absolute_error(targets_original, predictions_original)
r2 = r2_score(targets_original, predictions_original)
print(f"Test MAE: {mae:.4f} Hartree")
print(f"Test R²: {r2:.4f}")

Example - Adversarial Training:

# Train with PGD adversarial examples for robustness
robust_model, test_loader, scaler = train_mlp_qm9(
    att_index=7,                    # U0 property

train_gcn_qm9¶

function chemxai.train.train_gcn_qm9(target_idx=3, epochs=10, batch_size=64, lr=0.001, weight_decay=1e-4, n_noise=0, log_dir="logs")

Trains a Graph Convolutional Network on QM9 molecular graphs with automatic logging.

Parameters:

target_idx (int)
Target property index from QM9 dataset (0-14). Default: 3 (LUMO energy)
epochs (int)
Number of training epochs. Default: 10
batch_size (int)
Number of graphs per mini-batch. Default: 64
lr (float)
Learning rate for optimizer. Default: 0.001
weight_decay (float)
L2 regularization weight. Default: 1e-4
n_noise (int)
Number of noise graphs to include for robustness testing. Default: 0 (no noise)
log_dir (str)
Directory to save detailed training logs. Default: "logs"

Returns:

  • list – List of tuples (epoch, train_loss, val_loss) for each training epoch

Model Architecture:

Input: Node features (num_features-dimensional)
├── GCNConv(num_features → 256) + BatchNorm1d + ReLU
├── GCNConv(256 → 256) + BatchNorm1d + ReLU
├── GCNConv(256 → 256) + BatchNorm1d + ReLU
├── Global Add Pooling
├── Linear(256 → 256) + ReLU + Dropout(0.3)
└── Linear(256 → 1)
Output: Graph-level prediction

Training Process:

  1. Load QM9 molecular graphs with node features (atom type, chirality, etc.)
  2. Create graph representations with edge indices (bond connectivity)
  3. Split data using get_paired_dataloaders
  4. Automatically detect and use GPU if available
  5. Initialize GCN with 3 convolutional layers + BatchNorm
  6. Train with L1Loss (MAE)
  7. Save model checkpoint and detailed logs to log_dir
  8. Return training history (losses per epoch)

Example:

import torch
from chemxai.train import train_gcn_qm9

# Set device
device = torch.device('cuda' if torch.cuda.is_available() else 'cpu')

# Train GCN for internal energy prediction
model, test_loader, scaler, train_loader = train_gcn_qm9(
    target_idx=7,                   # U0 property
    epochs=50,
    batch_size=64,
    lr=0.01,
    weight_decay=5e-4,
    device=device,
    random_seed=42
)

# Evaluation
model.eval()
test_predictions = []
test_targets = []

with torch.no_grad():
    for batch in test_loader:
        batch = batch.to(device)
        pred = model(batch.x, batch.edge_index, batch.batch)
        test_predictions.append(pred.cpu())
        test_targets.append(batch.y[:, target_idx].cpu())

predictions = torch.cat(test_predictions).numpy()
targets = torch.cat(test_targets).numpy()

# Denormalize
predictions_real = scaler.inverse_transform(predictions.reshape(-1, 1))
targets_real = scaler.inverse_transform(targets.reshape(-1, 1))

# Metrics
from sklearn.metrics import mean_absolute_error, mean_squared_error
mae = mean_absolute_error(targets_real, predictions_real)
rmse = mean_squared_error(targets_real, predictions_real, squared=False)
print(f"Test MAE: {mae:.4f} Hartree")
print(f"Test RMSE: {rmse:.4f} Hartree")

main¶

function chemxai.train.main()

Command-line interface for training molecular property prediction models. Parses arguments and dispatches to appropriate training function.

Command-Line Arguments:

  • --model (str): Model type: 'mlp' or 'gcn'
  • --target (int): Target property index (0-11)
  • --epochs (int): Number of training epochs
  • --lr (float): Learning rate
  • --batch_size (int): Batch size
  • --descriptor (str): Descriptor type (MLP only)
  • --noise (float): Noise level (MLP only)
  • --layers (str): Hidden layers as comma-separated values (MLP only)
  • --seed (int): Random seed

Example Usage:

# Train MLP
python -m chemxai.train     --model mlp     --target 4     --epochs 100     --lr 0.001     --batch_size 64     --descriptor ECFPs     --layers 256,512,256     --seed 42

# Train GCN with GPU
python -m chemxai.train     --model gcn     --target 7     --epochs 50     --lr 0.01     --batch_size 32     --seed 42

Complete Workflow Example¶

import torch
from chemxai.train import train_mlp_qm9
from chemxai.explainers import Shap
from chemxai.plots import horizontal_bar_plot

# 1. Train model
model, test_loader, scaler = train_mlp_qm9(
    att_index=4,
    epochs=100,
    layers=[256, 512, 256],
    learning_rate=0.001,
    batch_size=64,
    descriptor='ECFPs',
    noise_level=0.0,
    attack_method=None,
    att_train_size=0,
    custom_att=None,
    random_seed=42
)

# 2. Save model checkpoint
torch.save({
    'model_state_dict': model.state_dict(),
    'scaler': scaler,
    'descriptor': 'ECFPs',
    'target_index': 4,
    'architecture': [256, 512, 256]
}, 'mlp_gap_qm9.pth')

# 3. Load and evaluate
checkpoint = torch.load('mlp_gap_qm9.pth')
model.load_state_dict(checkpoint['model_state_dict'])
model.eval()

# 4. Explain predictions
from chemxai.data import qm9_tabular
loader = qm9_tabular(descriptor_type='ECFPs')
train_features, _ = loader.load_data(target_idx=4)

shap_explainer = Shap(
    model=model,
    background_tensor=torch.tensor(train_features[:200], dtype=torch.float32),
    test_tensor=next(iter(test_loader))[0],
    device=model.device
)

global_importance = shap_explainer.explain_global()

# 5. Visualize
descriptor_names = [f'ECFP_bit_{i}' for i in range(2048)]
horizontal_bar_plot(
    feature_names=descriptor_names,
    values=global_importance,
    title='Global Feature Importance for HOMO-LUMO Gap',
    top_k=20
)

MLP vs GCN Comparison¶

Aspect train_mlp_qm9 train_gcn_qm9
Input Representation Fixed-size molecular descriptors Variable-size molecular graphs
Parameters 11 (highly configurable) 7 (simpler interface)
Descriptor Options 14 types (fingerprints, topological, etc.) Learned from graph structure
Adversarial Training Supported (PGD, FGSM) Not implemented
Data Augmentation Noise injection None (implicit from batching)
Training Speed Fast (dense operations) Medium (sparse graph operations)
Typical Accuracy Good (descriptor-dependent) Better (learns structure)
Memory Usage Fixed per molecule Scales with molecule size
Best Use Case Large datasets, quick experiments, adversarial robustness Smaller datasets, structural insights, graph-level tasks

Best Practices¶

Hyperparameter Tuning¶

  • Learning rate: Start with 0.001 for MLPs, 0.01 for GCNs. Reduce by 10x if loss plateaus.
  • Batch size: Larger batches (64-128) for MLPs, smaller (32-64) for GCNs due to memory.
  • Architecture: For MLPs, try pyramid structures (decreasing dimensions). For GCNs, 2-3 layers suffice.
  • Regularization: Use dropout (0.2-0.4) for MLPs, weight_decay (5e-4) for GCNs.

Data Preprocessing¶

  • Feature scaling: Always normalize features and targets (handled automatically).
  • Descriptor selection: ECFPs are generally most effective. Try multiple types for best results.
  • Train/val/test split: 80/10/10 is default. Increase validation set if hyperparameter tuning extensively.

Robustness Training¶

  • Noise injection: Use 0.05-0.15 for general robustness.
  • Adversarial training: PGD is stronger but slower. Start with att_train_size=100-500.
  • Evaluation: Test on both clean and noisy data to assess robustness.

Notes¶

  • Both functions automatically handle data loading, preprocessing, and train/val/test splits
  • Models are returned in evaluation mode (model.eval())
  • Target scalers must be used to denormalize predictions back to original units
  • QM9 properties have different units and scales - normalize targets before training
  • For reproducibility, always set random_seed consistently across runs
