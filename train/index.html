Overview¶

Complete training pipeline for MLP and GCN models with QM9 dataset. All parameters, configurations, and workflows documented.

MLP Training Function¶

train_mlp_qm9(att_index, epochs, layers, learning_rate, batch_size, descriptor, noise_level, attack_method, att_train_size, custom_att, random_seed)¶

Complete Parameter List (11 parameters):

  1. att_index (int): QM9 target property index (0-11)
    • 0: mu (dipole moment)
    • 1: alpha (isotropic polarizability)
    • 2: homo (HOMO energy)
    • 3: lumo (LUMO energy)
    • 4: gap (HOMO-LUMO gap)
    • 5: r2 (electronic spatial extent)
    • 6: zpve (zero point vibrational energy)
    • 7: U0 (internal energy at 0K)
    • 8: U (internal energy at 298K)
    • 9: H (enthalpy at 298K)
    • 10: G (free energy at 298K)
    • 11: Cv (heat capacity at 298K)
  2. epochs (int): Number of training epochs
  3. layers (list): Network architecture. Example: [64, 128, 64]
    • Length: number of hidden layers
    • Values: neurons per layer
  4. learning_rate (float): Optimizer learning rate. Typical: 0.001-0.01
  5. batch_size (int): Training batch size. Default: 32
  6. descriptor (str): Molecular descriptor type
    • 'ECFPs': Extended Connectivity Fingerprints
    • 'MACCSKeys': MACCS structural keys
    • 'Avalon': Avalon fingerprints
    • 'ErG': Estate + Gasteiger
    • 'pubchem': PubChem fingerprints
    • 'EstateIndices', 'fragments', 'moe_type', 'AUTOCORR2D', etc.
  7. noise_level (float): Noise intensity for training data. Range: 0.0-1.0
  8. attack_method (str): Attack type for adversarial training
    • 'PGD': Projected Gradient Descent
    • 'FGSM': Fast Gradient Sign Method
    • None: No attack
  9. att_train_size (int): Number of adversarial training samples
  10. custom_att (optional): Custom attack implementation
  11. random_seed (int): Seed for reproducibility. Default: 42

Returns:

  • model (torch.nn.Module): Trained MLP model
  • test_loader (DataLoader): Test data loader
  • target_scaler (StandardScaler): Scaler for predictions

Training Process:

  1. Load QM9 tabular data with specified descriptor
  2. Apply noise injection if noise_level > 0
  3. Create train/validation/test splits (80/10/10)
  4. Initialize MLP with specified layers
  5. Train with Adam optimizer + MSE loss
  6. Apply adversarial training if attack_method specified
  7. Return trained model + test data

GCN Training Function¶

train_gcn_qm9(target_idx=7, epochs=10, batch_size=32, lr=0.01, weight_decay=5e-4, device='cpu', random_seed=42)¶

Complete Parameter List (7 parameters):

  1. target_idx (int): QM9 target property (0-11). Default: 7 (U0)
  2. epochs (int): Training epochs. Default: 10
  3. batch_size (int): Batch size. Default: 32
  4. lr (float): Learning rate. Default: 0.01
  5. weight_decay (float): L2 regularization. Default: 5e-4
  6. device (str or torch.device): 'cpu' or 'cuda'. Default: 'cpu'
  7. random_seed (int): Random seed. Default: 42

Returns:

  • model (torch.nn.Module): Trained GCN model
  • test_loader (DataLoader): Test data loader
  • scaler (StandardScaler): Target scaler
  • train_loader (DataLoader): Training data loader

Training Process:

  1. Load QM9 graph dataset
  2. Create molecular graphs with node features (11D) and edge indices
  3. Split: 80% train, 10% val, 10% test
  4. Initialize GCN with 2 conv layers (11→64→64→1)
  5. Train with Adam optimizer + MSE loss
  6. Monitor validation loss for early stopping
  7. Return trained model + data loaders

GCN Training¶

from chemxai.train import train_gcn_qm9
import torch

device = torch.device('cuda' if torch.cuda.is_available() else 'cpu')

# Train GCN for internal energy U0
model, test_loader, scaler, train_loader = train_gcn_qm9(
    target_idx=7,             # U0
    epochs=50,
    batch_size=64,
    lr=0.01,
    weight_decay=5e-4,
    device=device,
    random_seed=42
)

# Evaluate
model.eval()
test_loss = 0
with torch.no_grad():
    for batch in test_loader:
        batch = batch.to(device)
        pred = model(batch.x, batch.edge_index, batch.batch)
        loss = torch.nn.functional.mse_loss(pred, batch.y[:, target_idx])
        test_loss += loss.item()

Complete Training Workflow¶

import torch
from chemxai.train import train_mlp_qm9, train_gcn_qm9
from chemxai.evaluate import evaluate_model

# 1. Train model
model, test_loader, scaler = train_mlp_qm9(
    att_index=4,
    epochs=100,
    layers=[128, 256, 128],
    learning_rate=0.001,
    batch_size=64,
    descriptor='ECFPs',
    noise_level=0.0,
    attack_method=None,
    att_train_size=0,
    custom_att=None,
    random_seed=42
)

# 2. Save model

    'model_state_dict': model.state_dict(),
    'scaler': scaler,
    'descriptor': 'ECFPs',
    'target_index': 4

# 3. Evaluate
metrics = evaluate_model(model, test_loader, scaler)
print(f"Test MAE: {metrics['mae']:.4f}")
print(f"Test R²: {metrics['r2']:.4f}")

Best Practices¶

MLP Training¶

  • Descriptor Selection: ECFPs for general use, MACCSKeys for quick tests, ErG for interpretability
  • Architecture: Start with [128, 256, 128], adjust based on descriptor size
  • Learning Rate: 0.001 for Adam, reduce if loss oscillates
  • Noise: Use 0.05-0.15 for robustness, higher for adversarial scenarios
  • Adversarial Training: PGD for strong robustness, FGSM for speed
  • Epochs: 100-200 sufficient for QM9, use early stopping

GCN Training¶

  • Learning Rate: 0.01 works well, reduce to 0.005 for stability
  • Weight Decay: 5e-4 for regularization, increase for overfitting
  • Batch Size: 32-64 for good gradient estimates
  • Epochs: 50-100 sufficient, GCNs converge faster than MLPs
  • Device: Use GPU for large datasets (10k+ molecules)

General Tips¶

  • Always set random_seed for reproducibility
  • Monitor both training and validation losses
  • Save best model based on validation performance
  • Use StandardScaler for target normalization
  • Evaluate on held-out test set only once
