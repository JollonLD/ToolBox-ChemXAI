chemxai.data¶

The data module provides dataset loaders, preprocessing utilities, and molecular descriptor generators for quantum chemistry and molecular property prediction tasks.

Dataset Classes¶

graph_datasets¶

class chemxai.data.graph_datasets()

Loads and preprocesses molecular graph datasets from PyTorch Geometric with support for noise injection variants.

Methods:

prepare_data_graph(dataset_name='PCQM4')

Loads graph dataset with normalization.

Parameters:

  • dataset_name (str) – Dataset name: 'PCQM4' or 'QM9'. Default: 'PCQM4'

Returns: torch_geometric.data.Dataset – Loaded and normalized molecular graph dataset

prepare_data_graph_noise(dataset_name='PCQM4', noise_type='gaussian', noise_scale=1.0, seed=42)

Prepares graph data with an additional noise feature for each node.

Parameters:

  • dataset_name (str) – Dataset name. Default: 'PCQM4'
  • noise_type (str) – Type of noise: 'gaussian', 'uniform', 'binary'. Default: 'gaussian'
  • noise_scale (float) – Scale of noise. Default: 1.0
  • seed (int) – Random seed. Default: 42

Returns: InMemoryDataset – Dataset with added noise feature on nodes

prepare_data_graph_edge_noise(dataset_name='PCQM4', noise_type='gaussian', noise_scale=1.0, seed=42)

Adds noise feature to graph edges.

Parameters:

  • dataset_name (str) – Dataset name. Default: 'PCQM4'
  • noise_type (str) – Noise type. Default: 'gaussian'
  • noise_scale (float) – Noise scale. Default: 1.0
  • seed (int) – Random seed. Default: 42

Returns: tuple – (modified_dataset, is_noise_mask) where is_noise_mask indicates which edge features are noise

prepare_data_subgraph_noise(dataset_name='PCQM4', subgraph_ratio=0.2, noise_type='gaussian', noise_scale=1.0, seed=42)

Adds noise only to a subgraph (subset of nodes) in each graph.

Parameters:

  • dataset_name (str) – Dataset name. Default: 'PCQM4'
  • subgraph_ratio (float) – Fraction of nodes to include in noisy subgraph (0-1). Default: 0.2
  • noise_type (str) – Noise type. Default: 'gaussian'
  • noise_scale (float) – Noise scale. Default: 1.0
  • seed (int) – Random seed. Default: 42

Returns: tuple – (modified_dataset, is_noisy_node_list) where is_noisy_node_list contains boolean masks per graph

prepare_data_graph_structural_noise(dataset_name='PCQM4', edge_ratio=0.1, seed=42)

Adds structural noise by inserting random edges into graphs.

Parameters:

  • dataset_name (str) – Dataset name. Default: 'PCQM4'
  • edge_ratio (float) – Fraction of random edges to add relative to original edge count. Default: 0.1
  • seed (int) – Random seed. Default: 42

Returns: tuple – (modified_dataset, is_noisy_edge_list) where is_noisy_edge_list contains boolean masks per graph

get_paired_dataloaders(dataset_name='QM9', batch_size=32, split_ratio=[0.8, 0.1, 0.1], shuffle=True, seed=42, noise_type='gaussian', noise_scale=1.0, n_noise=1)

Prepares paired dataloaders (normal and with noise) ensuring same train/val/test splits.

Parameters:

  • dataset_name (str) – Dataset name. Default: 'QM9'
  • batch_size (int) – Batch size. Default: 32
  • split_ratio (list) – Split ratios [train, val, test]. Default: [0.8, 0.1, 0.1]
  • shuffle (bool) – Whether to shuffle training data. Default: True
  • seed (int) – Random seed. Default: 42
  • noise_type (str) – Noise type. Default: 'gaussian'
  • noise_scale (float) – Noise scale. Default: 1.0
  • n_noise (int) – Number of noise features. Default: 1

Returns: tuple – Six dataloaders: (train_normal, val_normal, test_normal, train_noise, val_noise, test_noise)

Example:

from chemxai.data import graph_datasets

# Initialize loader
loader = graph_datasets()

# Load QM9 dataset
data = loader.prepare_data_graph(dataset_name='QM9')
print(f"Dataset size: {len(data)}")

# Load with node noise
noisy_data = loader.prepare_data_graph_noise(
    dataset_name='QM9',
    noise_type='gaussian',
    noise_scale=0.1,
    seed=42
)

# Get paired dataloaders for training
(train_normal, val_normal, test_normal,
 train_noise, val_noise, test_noise) = loader.get_paired_dataloaders(
    dataset_name='QM9',
    batch_size=32,
    split_ratio=[0.8, 0.1, 0.1],
    seed=42
)

qm9_tabular¶

class chemxai.data.qm9_tabular()

Generates tabular molecular descriptors from QM9 dataset. Automatically downloads and caches the dataset on first use.

Key Methods:

load_qm9_dataset(list_mols=None)

Loads complete QM9 dataset from .xyz files with caching.

Parameters:

  • list_mols (list, optional) – List of molecule atom counts to filter. If None, loads all. Default: None

Returns: tuple – (coords, properties, natoms) containing atomic coordinates, molecular properties, and atom counts

get_smiles(max_mols=None)

Extracts SMILES representations for all molecules.

Parameters:

  • max_mols (int, optional) – Maximum number of molecules to process. Default: None (all)

Returns: list – List of SMILES strings

df_props(include_smiles=False)

Creates a DataFrame with QM9 molecular properties.

Parameters:

  • include_smiles (bool) – If True, adds SMILES column. Default: False

Returns: pd.DataFrame – DataFrame with 15 molecular properties

get_coulomb_matrix(n_atoms_max=29, list_mols=[], n_jobs=4)

Calculates Coulomb matrices using DScribe.

Parameters:

  • n_atoms_max (int) – Maximum atoms for matrix padding. Default: 29
  • list_mols (list) – Molecule filter by atom count. Default: []
  • n_jobs (int) – Parallel threads. Default: 4

Returns: np.ndarray – Flattened Coulomb matrices

get_physicochemical_descriptors(n_jobs=4)

Computes RDKit physicochemical descriptors (MolWt, LogP, TPSA, etc.).

Parameters:

  • n_jobs (int) – Parallel threads. Default: 4

Returns: tuple – (descriptor_dataframe, valid_indices)

get_3d_descriptors(n_jobs=4, random_seed=42)

Computes 3D molecular descriptors (NPR1, NPR2, radius of gyration, etc.).

Parameters:

  • n_jobs (int) – Parallel threads. Default: 4
  • random_seed (int) – Random seed. Default: 42

Returns: tuple – (descriptor_dataframe, valid_indices)

get_morgan_fingerprints(radius=3, n_bits=512, n_jobs=4)

Computes Morgan (ECFP) fingerprints.

Parameters:

  • radius (int) – Morgan radius. Default: 3
  • n_bits (int) – Fingerprint length. Default: 512
  • n_jobs (int) – Parallel threads. Default: 4

Returns: tuple – (fingerprint_matrix, valid_indices)

compute_descriptors(descriptor_type='CM', morgan_radius=3, morgan_nBits=512, att_index=10, list_mols=[])

Unified descriptor computation method.

Parameters:

  • descriptor_type (str) – Descriptor type: 'CM' (Coulomb Matrix), 'Morgan', 'Physicochemical', '3D', 'MACCS', 'Topological', 'AtomPair', 'EState', 'Pattern', 'Avalon', 'MorganCount', 'Autocorr'. Default: 'CM'
  • morgan_radius (int) – Morgan radius. Default: 3
  • morgan_nBits (int) – Fingerprint bits. Default: 512
  • att_index (int) – Target property index (0-14). Default: 10
  • list_mols (list) – Molecule filter. Default: []

Returns: tuple – (X, Y, props) where X is descriptors, Y is target property, props is all properties

get_paired_dataloaders_tabular(att_index=10, batch_size=256, descriptor_type='CM', split_ratio=[0.8, 0.1, 0.1], seed=42, noise_type='gaussian', noise_scale=1.0, n_noise=1, add_noise=True, cache_descriptors=True, ...)

Creates paired DataLoaders (normal and with noise) for training.

Key Parameters:

  • att_index (int) – Target property index. Default: 10
  • batch_size (int) – Batch size. Default: 256
  • descriptor_type (str) – Descriptor type. Default: 'CM'
  • split_ratio (list) – [train, val, test] split. Default: [0.8, 0.1, 0.1]
  • seed (int) – Random seed. Default: 42
  • noise_type (str) – 'gaussian', 'uniform', or 'binary'. Default: 'gaussian'
  • n_noise (int) – Number of noise features. Default: 1
  • add_noise (bool) – Whether to add noise. Default: True

Returns: tuple – If add_noise=True: (train_normal, val_normal, test_normal, train_noise, val_noise, test_noise, is_noise_mask). If add_noise=False: (train_normal, val_normal, test_normal, None)

get_descriptor_names(descriptor_type='Morgan', morgan_radius=2, morgan_nBits=512)

Returns feature names for a descriptor type.

Parameters:

  • descriptor_type (str) – Descriptor type. Default: 'Morgan'
  • morgan_radius (int) – Morgan radius. Default: 2
  • morgan_nBits (int) – Fingerprint bits. Default: 512

Returns: list – List of feature names

Supported Descriptor Types:

  • 'CM' – Coulomb Matrix (n_atoms² features)
  • 'Morgan' – Morgan/ECFP fingerprints (circular)
  • 'Physicochemical' – RDKit molecular properties (MW, LogP, TPSA, H-donors, H-acceptors, etc.)
  • '3D' – 3D shape descriptors (NPR, radius of gyration, etc.)
  • 'MACCS' – MACCS structural keys (166-bit)
  • 'Topological' – Topological fingerprints
  • 'AtomPair' – Atom pair fingerprints
  • 'EState' – E-State indices (79 features)
  • 'Pattern' – Pattern fingerprints
  • 'Avalon' – Avalon fingerprints
  • 'MorganCount' – Morgan count fingerprints (with occurrence counts)
  • 'Autocorr' – 2D autocorrelation descriptors

Example:

from chemxai.data import qm9_tabular

# Initialize loader
loader = qm9_tabular()

# Load raw QM9 data
coords, props, natoms = loader.load_qm9_dataset()
print(f"Loaded {len(coords)} molecules")

# Get SMILES
smiles = loader.get_smiles(max_mols=1000)

# Get molecular properties as DataFrame
df = loader.df_props(include_smiles=True)
print(df.head())

# Compute Morgan fingerprints
X, Y, props = loader.compute_descriptors(
    descriptor_type='Morgan',
    morgan_radius=2,
    morgan_nBits=2048,
    att_index=7  # U0 property
)
print(f"Descriptor shape: {X.shape}")
print(f"Target shape: {Y.shape}")

# Create paired dataloaders for training
dataloaders = loader.get_paired_dataloaders_tabular(
    att_index=7,
    batch_size=64,
    descriptor_type='Morgan',
    morgan_radius=2,
    morgan_nBits=2048,
    split_ratio=[0.8, 0.1, 0.1],
    seed=42,
    noise_type='gaussian',
    noise_scale=0.1,
    n_noise=10,
    add_noise=True
)

if len(dataloaders) == 7:
    (train_normal, val_normal, test_normal,
     train_noise, val_noise, test_noise, is_noise) = dataloaders
    print(f"Training batches (normal): {len(train_normal)}")
    print(f"Noise features: {is_noise.sum()}")
else:
    train_normal, val_normal, test_normal, _ = dataloaders
    print(f"Training batches: {len(train_normal)}")

# Get feature names
feature_names = loader.get_descriptor_names(
    descriptor_type='Morgan',
    morgan_radius=2,
    morgan_nBits=2048
)
print(f"Number of features: {len(feature_names)}")

from chemxai.data import qm9_tabular
import numpy as np

# Load QM9 with ECFP descriptors
loader = qm9_tabular(descriptor_type='ECFPs')

print(f"Feature matrix shape: {features.shape}")
print(f"Target shape: {targets.shape}")

# Compute custom ECFP with different parameters
custom_ecfp = loader.compute_ECFPs(radius=3, n_bits=4096)

loader_maccs = qm9_tabular(descriptor_type='MACCSKeys')

# Save for later use
loader.save_descriptors('qm9_ecfp_descriptors.npz')

Cluster¶

class chemxai.data.Cluster(n_clusters=5, method='kmeans')

Performs clustering analysis on molecular descriptors for dataset stratification and analysis.

Parameters:

  • n_clusters (int) – Number of clusters to generate. Default: 5
  • method (str) – Clustering algorithm: 'kmeans', 'hierarchical', or 'dbscan'. Default: 'kmeans'

Methods:

fit(features)

Fits the clustering model to descriptor features.

Parameters:

  • features (numpy.ndarray) – Descriptor matrix of shape (num_samples, num_features)

Returns: self – Fitted clustering model

predict(features)

Assigns cluster labels to new data points.

Parameters:

  • features (numpy.ndarray) – Descriptor matrix to cluster

Returns: numpy.ndarray – Cluster labels of shape (num_samples,)

fit_predict(features)

Fits model and returns cluster assignments in one step.

Parameters:

  • features (numpy.ndarray) – Descriptor matrix

Returns: numpy.ndarray – Cluster labels

get_cluster_centers()

Returns cluster centroid coordinates.

Returns: numpy.ndarray – Centroid matrix of shape (n_clusters, num_features)

get_cluster_sizes()

Returns number of samples in each cluster.

Returns: dict – Mapping from cluster_id to sample count

compute_silhouette_score()

Computes silhouette coefficient to evaluate clustering quality.

Returns: float – Silhouette score in range [-1, 1], higher is better

visualize_clusters(method='pca', figsize=(10, 8))

Visualizes clusters using dimensionality reduction.

Parameters:

  • method (str) – Dimensionality reduction: 'pca', 'tsne', or 'umap'. Default: 'pca'
  • figsize (tuple) – Figure size. Default: (10, 8)

Returns: matplotlib.figure.Figure – Cluster visualization

stratified_split(labels, train_ratio=0.8, random_seed=42)

Creates stratified train/test splits ensuring cluster representation.

Parameters:

  • labels (numpy.ndarray) – Cluster assignments
  • train_ratio (float) – Fraction for training. Default: 0.8
  • random_seed (int) – Random seed. Default: 42

Returns: tuple – (train_indices, test_indices)

Example:

from chemxai.data import qm9_tabular, Cluster
from sklearn.preprocessing import StandardScaler

# Load and prepare data
loader = qm9_tabular(descriptor_type='ECFPs')
features, targets = loader.load_data(target_idx=7)

# Standardize features
scaler = StandardScaler()
features_scaled = scaler.fit_transform(features)

# Perform K-means clustering
clusterer = Cluster(n_clusters=8, method='kmeans')
cluster_labels = clusterer.fit_predict(features_scaled)

# Evaluate clustering quality
silhouette = clusterer.compute_silhouette_score()
print(f"Silhouette score: {silhouette:.3f}")

# Get cluster information
centers = clusterer.get_cluster_centers()
sizes = clusterer.get_cluster_sizes()
print(f"Cluster sizes: {sizes}")

# Visualize clusters
fig = clusterer.visualize_clusters(method='tsne', figsize=(12, 10))

# Create stratified splits
train_idx, test_idx = clusterer.stratified_split(
    cluster_labels,
    train_ratio=0.8,
    random_seed=42
)

Notes¶

  • All descriptor computations require RDKit to be installed
  • For large datasets (>100k molecules), consider using sparse matrix representations for fingerprint descriptors
  • When using noise injection, apply it only to training data to avoid test set contamination
  • QM9 target properties are provided in original units (Hartree, Bohr³, etc.) - normalize before training
