chemxai.data¶

The data module provides dataset loaders, preprocessing utilities, and molecular descriptor generators for quantum chemistry and molecular property prediction tasks.

Dataset Classes¶

graph_datasets¶

class chemxai.data.graph_datasets(dataset_name='qm9')

Loads and preprocesses molecular graph datasets with support for various quantum chemistry databases.

Parameters:

  • dataset_name (str) – Name of the dataset to load. Options include:
    • 'qm9' – QM9 dataset with ~134k organic molecules and 19 quantum properties
    • 'esol' – ESOL dataset for aqueous solubility prediction
    • 'freesolv' – FreeSolv dataset for hydration free energies
    • 'lipo' – Lipophilicity dataset for octanol/water distribution coefficient
    Default: 'qm9'

Methods:

load_data()

Loads the specified dataset from disk or downloads if not available.

Returns: torch_geometric.data.Dataset – PyTorch Geometric dataset object containing molecular graphs

get_statistics()

Computes statistical properties of the dataset.

Returns: dict – Dictionary containing:

  • 'num_molecules' (int) – Total number of molecules
  • 'num_atoms_mean' (float) – Average number of atoms per molecule
  • 'num_bonds_mean' (float) – Average number of bonds per molecule
  • 'num_features' (int) – Node feature dimensionality

split_data(train_ratio=0.8, val_ratio=0.1, test_ratio=0.1, random_seed=42)

Creates train/validation/test splits with stratification support.

Parameters:

  • train_ratio (float) – Fraction of data for training. Default: 0.8
  • val_ratio (float) – Fraction for validation. Default: 0.1
  • test_ratio (float) – Fraction for testing. Default: 0.1
  • random_seed (int) – Random seed for reproducibility. Default: 42

Returns: tuple – (train_dataset, val_dataset, test_dataset)

get_target_statistics(target_idx)

Computes statistics for a specific target property.

Parameters:

  • target_idx (int) – Index of target property (0-18 for QM9)

Returns: dict – Statistics including mean, std, min, max, median

normalize_features(method='standard')

Normalizes node features using specified method.

Parameters:

  • method (str) – Normalization method: 'standard', 'minmax', or 'robust'. Default: 'standard'

Returns: self – Returns self for method chaining

filter_by_size(min_atoms=None, max_atoms=None)

Filters molecules by number of atoms.

Parameters:

  • min_atoms (int, optional) – Minimum number of atoms. Default: None
  • max_atoms (int, optional) – Maximum number of atoms. Default: None

Returns: self – Filtered dataset

Example:

from chemxai.data import graph_datasets

# Load QM9 dataset
dataset = graph_datasets(dataset_name='qm9')
data = dataset.load_data()

# Get statistics
stats = dataset.get_statistics()
print(f"Number of molecules: {stats['num_molecules']}")
print(f"Average atoms per molecule: {stats['num_atoms_mean']:.2f}")

# Create splits
train_data, val_data, test_data = dataset.split_data(
    train_ratio=0.8,
    val_ratio=0.1,
    test_ratio=0.1,
    random_seed=42
)

# Normalize features
dataset.normalize_features(method='standard')

# Filter by molecular size
dataset.filter_by_size(min_atoms=5, max_atoms=50)

qm9_tabular¶

class chemxai.data.qm9_tabular(descriptor_type='ECFPs')

Generates tabular molecular descriptors from QM9 dataset for traditional machine learning and neural network models.

Parameters:

  • descriptor_type (str) – Type of molecular descriptor to generate. Available options:
    • 'ECFPs' – Extended-Connectivity Fingerprints (Morgan fingerprints, 2048-bit)
    • 'MACCSKeys' – 166-bit MACCS structural keys
    • 'Avalon' – Avalon fingerprints (512-bit)
    • 'ErG' – Estate indices + Gasteiger charges
    • 'pubchem' – PubChem fingerprints (881-bit)
    • 'EstateIndices' – Electrotopological state indices
    • 'fragments' – Fragment-based descriptors
    • 'graph' – Graph-based descriptors
    • 'moe_type' – MOE-type descriptors
    • 'constitutional' – Constitutional descriptors
    • 'AUTOCORR2D' – 2D autocorrelation descriptors
    • 'charge' – Charge-based descriptors
    • 'connectivity' – Connectivity indices
    • 'kappa' – Kappa shape indices
    Default: 'ECFPs'

Methods:

load_data(target_idx=7)

Loads QM9 dataset and generates specified molecular descriptors.

Parameters:

  • target_idx (int) – Index of target property to predict (0-18). Default: 7 (U0 - internal energy at 0K)

Returns: tuple – (features, targets) where:

  • features (numpy.ndarray) – Descriptor matrix of shape (num_molecules, num_features)
  • targets (numpy.ndarray) – Target values of shape (num_molecules,)

compute_ECFPs(radius=2, n_bits=2048)

Computes Extended-Connectivity Fingerprints using RDKit.

Parameters:

  • radius (int) – Radius for Morgan algorithm. Default: 2
  • n_bits (int) – Fingerprint length. Default: 2048

Returns: numpy.ndarray – Binary fingerprint matrix

compute_MACCSKeys()

Computes 166-bit MACCS structural keys representing common substructures.

Returns: numpy.ndarray – MACCS keys matrix of shape (num_molecules, 166)

compute_Avalon(n_bits=512)

Computes Avalon fingerprints.

Parameters:

  • n_bits (int) – Fingerprint length. Default: 512

Returns: numpy.ndarray – Avalon fingerprint matrix

compute_ErG()

Computes Estate (electrotopological state) indices combined with Gasteiger partial charges.

Returns: numpy.ndarray – Combined descriptor matrix

compute_pubchem()

Computes 881-bit PubChem fingerprints.

Returns: numpy.ndarray – PubChem fingerprint matrix

compute_EstateIndices()

Computes electrotopological state indices for each atom type.

Returns: numpy.ndarray – Estate indices matrix

compute_fragments()

Computes fragment-based descriptors (functional groups, ring systems).

Returns: numpy.ndarray – Fragment descriptor matrix

compute_graph()

Computes graph-theoretical descriptors (Wiener index, Zagreb indices, etc.).

Returns: numpy.ndarray – Graph descriptor matrix

compute_moe_type()

Computes MOE-type (Molecular Operating Environment) descriptors.

Returns: numpy.ndarray – MOE descriptor matrix

compute_constitutional()

Computes constitutional descriptors (atom counts, molecular weight, etc.).

Returns: numpy.ndarray – Constitutional descriptor matrix

compute_AUTOCORR2D()

Computes 2D autocorrelation descriptors based on molecular properties.

Returns: numpy.ndarray – Autocorrelation descriptor matrix

compute_charge()

Computes charge-related descriptors (partial charges, charge distribution).

Returns: numpy.ndarray – Charge descriptor matrix

compute_connectivity()

Computes molecular connectivity indices (Randić, Balaban, etc.).

Returns: numpy.ndarray – Connectivity descriptor matrix

compute_kappa()

Computes kappa shape indices describing molecular shape.

Returns: numpy.ndarray – Kappa descriptor matrix

inject_noise(noise_level=0.1, random_seed=42)

Injects Gaussian noise into descriptor features for robustness testing.

Parameters:

  • noise_level (float) – Standard deviation of Gaussian noise relative to feature std. Default: 0.1
  • random_seed (int) – Random seed for reproducibility. Default: 42

Returns: numpy.ndarray – Noisy descriptor matrix

get_descriptor_names()

Returns human-readable names for each descriptor dimension.

Returns: list – List of descriptor names

save_descriptors(filepath)

Saves computed descriptors to disk.

Parameters:

  • filepath (str) – Path to save file (.npz format)
load_descriptors(filepath)

Loads previously computed descriptors from disk.

Parameters:

  • filepath (str) – Path to saved descriptors (.npz format)

Returns: tuple – (features, targets)

Example:

from chemxai.data import qm9_tabular
import numpy as np

# Load QM9 with ECFP descriptors
loader = qm9_tabular(descriptor_type='ECFPs')
features, targets = loader.load_data(target_idx=7)

print(f"Feature matrix shape: {features.shape}")
print(f"Target shape: {targets.shape}")

# Compute custom ECFP with different parameters
custom_ecfp = loader.compute_ECFPs(radius=3, n_bits=4096)

# Try different descriptor types
loader_maccs = qm9_tabular(descriptor_type='MACCSKeys')
maccs_features, _ = loader_maccs.load_data(target_idx=7)

# Add noise for robustness testing
noisy_features = loader.inject_noise(noise_level=0.15)

# Get descriptor names for interpretability
descriptor_names = loader.get_descriptor_names()
print(f"First 5 descriptors: {descriptor_names[:5]}")

# Save for later use
loader.save_descriptors('qm9_ecfp_descriptors.npz')

Cluster¶

class chemxai.data.Cluster(n_clusters=5, method='kmeans')

Performs clustering analysis on molecular descriptors for dataset stratification and analysis.

Parameters:

  • n_clusters (int) – Number of clusters to generate. Default: 5
  • method (str) – Clustering algorithm: 'kmeans', 'hierarchical', or 'dbscan'. Default: 'kmeans'

Methods:

fit(features)

Fits the clustering model to descriptor features.

Parameters:

  • features (numpy.ndarray) – Descriptor matrix of shape (num_samples, num_features)

Returns: self – Fitted clustering model

predict(features)

Assigns cluster labels to new data points.

Parameters:

  • features (numpy.ndarray) – Descriptor matrix to cluster

Returns: numpy.ndarray – Cluster labels of shape (num_samples,)

fit_predict(features)

Fits model and returns cluster assignments in one step.

Parameters:

  • features (numpy.ndarray) – Descriptor matrix

Returns: numpy.ndarray – Cluster labels

get_cluster_centers()

Returns cluster centroid coordinates.

Returns: numpy.ndarray – Centroid matrix of shape (n_clusters, num_features)

get_cluster_sizes()

Returns number of samples in each cluster.

Returns: dict – Mapping from cluster_id to sample count

compute_silhouette_score()

Computes silhouette coefficient to evaluate clustering quality.

Returns: float – Silhouette score in range [-1, 1], higher is better

visualize_clusters(method='pca', figsize=(10, 8))

Visualizes clusters using dimensionality reduction.

Parameters:

  • method (str) – Dimensionality reduction: 'pca', 'tsne', or 'umap'. Default: 'pca'
  • figsize (tuple) – Figure size. Default: (10, 8)

Returns: matplotlib.figure.Figure – Cluster visualization

stratified_split(labels, train_ratio=0.8, random_seed=42)

Creates stratified train/test splits ensuring cluster representation.

Parameters:

  • labels (numpy.ndarray) – Cluster assignments
  • train_ratio (float) – Fraction for training. Default: 0.8
  • random_seed (int) – Random seed. Default: 42

Returns: tuple – (train_indices, test_indices)

Example:

from chemxai.data import qm9_tabular, Cluster
from sklearn.preprocessing import StandardScaler

# Load and prepare data
loader = qm9_tabular(descriptor_type='ECFPs')
features, targets = loader.load_data(target_idx=7)

# Standardize features
scaler = StandardScaler()
features_scaled = scaler.fit_transform(features)

# Perform K-means clustering
clusterer = Cluster(n_clusters=8, method='kmeans')
cluster_labels = clusterer.fit_predict(features_scaled)

# Evaluate clustering quality
silhouette = clusterer.compute_silhouette_score()
print(f"Silhouette score: {silhouette:.3f}")

# Get cluster information
centers = clusterer.get_cluster_centers()
sizes = clusterer.get_cluster_sizes()
print(f"Cluster sizes: {sizes}")

# Visualize clusters
fig = clusterer.visualize_clusters(method='tsne', figsize=(12, 10))

# Create stratified splits
train_idx, test_idx = clusterer.stratified_split(
    cluster_labels,
    train_ratio=0.8,
    random_seed=42
)

Notes¶

  • All descriptor computations require RDKit to be installed
  • For large datasets (>100k molecules), consider using sparse matrix representations for fingerprint descriptors
  • When using noise injection, apply it only to training data to avoid test set contamination
  • QM9 target properties are provided in original units (Hartree, Bohr³, etc.) - normalize before training
