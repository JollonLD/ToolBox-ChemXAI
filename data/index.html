Data Module - Complete Documentation¶

Overview¶

The Data Module (data.py) provides comprehensive utilities for loading, preprocessing, and transforming molecular datasets for both tabular and graph-based machine learning models. It supports the QM9 and PCQM4Mv2 datasets with 14+ different molecular descriptor types.

Graph-Based Classes¶

CastXToFloat¶

Transform class to convert node features to float type.

class CastXToFloat:
    def __call__(self, data):
        data.x = data.x.float()
        return data

graph_datasets¶

Main class for handling graph-based molecular datasets from PyTorch Geometric.

__init__()¶

graph_datasets()

Initializes the graph datasets handler. No parameters required.

prepare_data_graph()¶

prepare_data_graph(dataset_name='PCQM4')

Loads and prepares graph-based molecular datasets with normalization.

Parameters:

  • dataset_name (str): Name of the dataset. Options:
    • 'PCQM4': PCQM4Mv2 dataset with ~3.8M molecules (default)
    • 'QM9': QM9 dataset with ~133k molecules

Returns:

  • torch_geometric.data.InMemoryDataset: Dataset with normalized node features

Example:

graph_data = graph_datasets()
qm9_dataset = graph_data.prepare_data_graph('QM9')
print(f"Dataset size: {len(qm9_dataset)}")
print(f"Node features: {qm9_dataset[0].x.shape}")

prepare_data_graph_noise()¶

prepare_data_graph_noise(dataset_name='PCQM4', noise_type='gaussian', 
                         noise_scale=1.0, seed=42)

Prepares graph data with an additional noise feature for each node (for robustness testing).

Parameters:

  • dataset_name (str): Dataset to load ('PCQM4' or 'QM9')
  • noise_type (str): Type of noise to add:
    • 'gaussian': Gaussian/normal distribution noise
    • 'uniform': Uniform distribution noise in [-scale, scale]
    • 'binary': Binary noise (0 or 1)
  • noise_scale (float): Scale/magnitude of the noise. Default: 1.0
  • seed (int): Random seed for reproducibility. Default: 42

Returns:

  • NoisyGraphDataset: Custom dataset with added noise feature. Contains is_noise boolean mask.

prepare_data_graph_edge_noise(dataset_name='PCQM4', noise_type='gaussian',
                              noise_scale=1.0, seed=42)

Adds noise features to graph edges.

Parameters:

  • dataset_name (str): Dataset name
  • noise_type (str): Type of noise ('gaussian', 'uniform', 'binary')
  • noise_scale (float): Noise magnitude
  • seed (int): Random seed

Returns:

  • tuple: (modified_dataset, is_noise_mask) where is_noise_mask identifies noise features

prepare_data_subgraph_noise(dataset_name='PCQM4', subgraph_ratio=0.2,

get_paired_dataloaders()¶

get_paired_dataloaders(dataset_name='QM9', batch_size=32, 
                      split_ratio=[0.8, 0.1, 0.1], shuffle=True,
                      seed=42, noise_type='gaussian', noise_scale=1.0, n_noise=1)

Prepares paired DataLoaders (normal and noisy) with consistent train/val/test splits.

Tabular Data Class¶

qm9_tabular¶

Comprehensive class for loading QM9 dataset and computing various molecular descriptors.

__init__()¶

qm9_tabular()

Initializes the QM9 tabular data handler. Automatically downloads and extracts QM9 dataset if not present.

Behavior:

  • Downloads QM9.zip from Dropbox if not found locally
  • Extracts to data/QM9_tabular_Data/
  • Caches downloaded data for future use

Properties Attribute¶

The class contains 15 QM9 molecular properties (indices 0-14):

  1. Rotational constant A (GHz)
  2. Rotational constant B (GHz)
  3. Rotational constant C (GHz)
  4. Dipole moment (μ) in Debye
  5. Isotropic polarizability (α) in a.u.
  6. Energy of HOMO (ϵHOMO) in Hartree
  7. Energy of LUMO (ϵLUMO) in Hartree
  8. Gap (ϵgap) in Hartree
  9. Electronic spatial extent in a.u.
  10. Zero point vibrational energy (zpve) in Hartree
  11. Internal energy at 0 K (U0) in Hartree
  12. Internal energy at 298.15 K (U) in Hartree
  13. Enthalpy at 298.15 K (H) in Hartree
  14. Free energy at 298.15 K (G) in Hartree
  15. Heat capacity at 298.15 K (Cv) in cal/mol·K

compute_descriptors()¶

compute_descriptors(descriptor_type='CM', morgan_radius=3, morgan_nBits=512,
                   att_index=10, list_mols=[])

Computes molecular descriptors for all molecules in QM9 dataset.

Parameters:

  • descriptor_type (str): Type of molecular descriptor. Options:
    • 'CM': Coulomb Matrix (quantum mechanical)
    • 'Morgan': Morgan Fingerprints (ECFP)
    • 'MorganCount': Morgan with count information
    • 'Physicochemical': 2D physicochemical properties
    • '3D': Geometry-based 3D descriptors
    • 'MACCS': MACCS Keys (166 bits)
    • 'Topological': Daylight-like topological fingerprints
    • 'AtomPair': Atom pair fingerprints
    • 'EState': Electrotopological state indices
    • 'Pattern': SMARTS pattern fingerprints
    • 'Avalon': Avalon fingerprints
    • 'Autocorr': 2D autocorrelation descriptors
    • 'RDKit2D': Comprehensive RDKit 2D descriptors
    • 'Mordred': Complete Mordred descriptor set (1800+ features)
  • morgan_radius (int): Radius for Morgan fingerprints. Default: 3
  • morgan_nBits (int): Number of bits for fingerprints. Default: 512
  • att_index (int): Index of property to predict (0-14). Default: 10 (U0)
  • list_mols (list): Filter molecules by number of atoms. Empty = all molecules

Returns:

  • tuple: (X, Y, props) where:
    • X: NumPy array of descriptors [n_samples, n_features]
    • Y: NumPy array of target property [n_samples, 1]
    • props: NumPy array of all 15 properties [n_samples, 15]

get_paired_dataloaders_tabular()¶

get_paired_dataloaders_tabular(att_index=10, batch_size=256, descriptor_type='CM',
                              list_mols=[], split_ratio=[0.8, 0.1, 0.1], seed=42,
                              noise_type='gaussian', noise_scale=1.0, n_noise=1,
                              morgan_radius=3, morgan_nBits=512, add_noise=True,
                              cache_descriptors=True)

Main method to prepare complete paired DataLoaders for tabular molecular data.

Parameters:

  • att_index (int): Property index to predict (0-14). Default: 10
  • batch_size (int): Batch size. Default: 256
  • descriptor_type (str): Descriptor type (see compute_descriptors)
  • list_mols (list): Molecule filter by atom count
  • split_ratio (list): [train, val, test] split. Default: [0.8, 0.1, 0.1]
  • seed (int): Random seed for reproducibility
  • noise_type (str): Type of noise ('gaussian', 'uniform', 'binary')
  • noise_scale (float): Noise magnitude
  • n_noise (int): Number of noise features
  • morgan_radius (int): Morgan fingerprint radius
  • morgan_nBits (int): Morgan fingerprint bits
  • add_noise (bool): Whether to create noisy dataset. Default: True
  • cache_descriptors (bool): Cache computed descriptors. Default: True

Returns:

  • tuple: (train_normal, val_normal, test_normal, train_noise, val_noise, test_noise, is_noise_mask)
    • 6 DataLoaders (3 for normal data, 3 for noisy data)
    • is_noise_mask: Boolean array indicating which features are noise

Complete Usage Examples¶

Example 1: Basic Tabular Data Loading¶

from chemxai.data import qm9_tabular

# Initialize
qm9 = qm9_tabular()

# Load data with Morgan fingerprints
train_loader, val_loader, test_loader, *_ = qm9.get_paired_dataloaders_tabular(
    att_index=7,  # Predict HOMO-LUMO gap
    descriptor_type='Morgan',
    batch_size=64,
    morgan_radius=2,
    morgan_nBits=1024,
    add_noise=False  # No noise dataset
)

# Iterate through batches
for features, targets in train_loader:
    print(f"Batch features shape: {features.shape}")
    print(f"Batch targets shape: {targets.shape}")
    break

Example 3: Comparing Multiple Descriptors¶

qm9 = qm9_tabular()

descriptors = ['Morgan', 'MACCS', 'Physicochemical', '3D']
results = {}

for desc_type in descriptors:
    # Compute descriptors
    X, Y, props = qm9.compute_descriptors(
        descriptor_type=desc_type,
        att_index=10
    )
    
    # Get feature names
    feature_names = qm9.get_descriptor_names(descriptor_type=desc_type)
    
    # Get details
    details = qm9.get_descriptor_details(descriptor_type=desc_type)
    
    results[desc_type] = {
        'n_features': X.shape[1],
        'n_samples': X.shape[0],
        'details': details
    }
    
    print(f"
{desc_type}:")
    print(f"  Features: {X.shape[1]}")
    print(f"  Description: {details['description']}")

Performance Considerations¶

  • Caching: Descriptors are cached to disk for faster repeated access
  • Parallel Processing: Uses ThreadPoolExecutor for large datasets
  • Memory Efficiency: Lazy loading and batch processing for large datasets
  • Reproducibility: All random operations use configurable seeds

Best Practices¶

  1. Enable caching with cache_descriptors=True for repeated experiments
  2. Start small: Test with list_mols filter before processing full dataset
  3. Choose appropriate descriptors: Use get_descriptor_details() to understand each type
  4. Normalize data: The module automatically normalizes using StandardScaler
  5. Use paired loaders for robustness evaluation (normal + noisy data)
