Tabular Explainers Overview¶

The XAI Toolbox provides powerful explainers specifically designed for tabular data models. These explainers help you understand how your model makes predictions on structured data by identifying important features and their impact on the model's output.

Available Tabular Explainers¶

This toolbox includes the following explainers for tabular data:

  1. SHAP (SHapley Additive exPlanations): A unified approach to explain the output of any machine learning model using Shapley values from coalitional game theory.
  2. LIME (Local Interpretable Model-agnostic Explanations): Creates a locally interpretable model around a specific prediction to explain how the model behaves in that local region.

Choosing the Right Explainer¶

Both SHAP and LIME are powerful techniques, but they have different strengths and applications:

Feature SHAP LIME
Theoretical basis Shapley values (game theory) Local linear approximation
Consistency Higher (mathematically consistent) Lower (may vary with sample size)
Speed Slower (especially for larger models) Faster (good for quick explorations)
Visualization Built-in visualization capabilities Simpler, direct visualizations
Local/Global Both Primarily local

When to use SHAP:¶

  • When you need explanations with stronger theoretical guarantees
  • When you want both local and global interpretations
  • When computational cost is not a major concern
  • When you need consistent feature attributions

When to use LIME:¶

  • When you need quick explanations
  • When you're mainly interested in local explanations
  • When you want to understand specific predictions
  • When computational efficiency is important

Common Usage Pattern¶

Most tabular explainers follow a similar pattern:

  1. Initialize the explainer with your model and data loaders
  2. Generate local explanations for specific instances
  3. Generate global explanations to understand overall model behavior
  4. Visualize or analyze the feature importances
# General pattern
explainer = Explainer(model, background_tensor, test_tensor, device)
local_explanation = explainer.explain_local(index)
global_explanation = explainer.explain_global()
