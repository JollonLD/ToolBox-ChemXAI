LIME (Local Interpretable Model-agnostic Explanations)¶

The LIME explainer in the XAI Toolbox implements the Local Interpretable Model-agnostic Explanations algorithm for tabular data. LIME helps explain individual predictions of any black-box machine learning model by learning an interpretable model locally around the prediction.

Theory¶

LIME works by creating a locally interpretable model around a specific prediction. It generates perturbed samples around the instance being explained, gets predictions from the black-box model for these samples, and then trains a simpler, interpretable model (typically a sparse linear model) on this neighborhood.

Key principles of LIME:

  • Local Fidelity: The explanation must approximate the model well in the vicinity of the instance being explained
  • Interpretability: The explanation should be easy to understand (sparse and explainable)
  • Model-Agnostic: The explanation method should work with any model

Implementation¶

The LIME class in the XAI Toolbox uses the lime_tabular module from the original LIME package, adapted to work with PyTorch models and DataLoaders. It supports both classification and regression models.

Usage¶

Initialization¶

from xai_toolbox import LIME

explainer = LIME(model, train_loader, test_loader, device, mode='regression')

Parameters: - model: The model to be explained - train_loader: DataLoader for the training set (used to understand feature distributions) - test_loader: DataLoader for the test set (contains instances to explain) - device: Device (CPU or GPU) for operations - mode: Either 'regression' or 'classification' depending on the model type

Local Explanation¶

Get feature importance for a specific instance:

lime_explanation = explainer.local_explanation(index=0, num_features=10)
print(lime_explanation)

Parameters: - index: Index of the instance in the test set to be explained - num_features: Number of features to include in the explanation (defaults to all features)

Returns a DataFrame with feature names and their LIME values, sorted by importance.

Example¶

import torch
import matplotlib.pyplot as plt
from xai_toolbox import LIME

# Assume model and data loaders are defined
explainer = LIME(model, train_loader, test_loader, device, mode='regression')

# Get local explanation for first test instance
local_exp = explainer.local_explanation(index=0, num_features=10)

# Plot the feature importance
plt.figure(figsize=(10, 6))
plt.barh(local_exp['Feature'], local_exp['LIME Value'])
plt.xlabel('LIME Value')
plt.ylabel('Feature')
plt.title('Feature Importance for Instance #0')
plt.tight_layout()
plt.show()

# Compare explanations for multiple instances
fig, axes = plt.subplots(3, 1, figsize=(12, 12))
for i, ax in enumerate(axes):
    exp = explainer.local_explanation(index=i, num_features=5)
    ax.barh(exp['Feature'], exp['LIME Value'])
    ax.set_title(f'Explanation for Instance #{i}')
    ax.set_xlabel('LIME Value')
plt.tight_layout()
plt.show()

Customization¶

The LIME explainer can be customized in several ways:

  • Adjust the number of features in the explanation
  • Modify the kernel width for the exponential kernel
  • Change the discretization method for continuous features
  • Use different feature selection methods

Refer to the lime package documentation for more customization options.

Limitations¶

  • Stability: LIME explanations can be unstable if insufficient samples are used
  • Feature Dependence: LIME assumes feature independence which might not hold
  • Locality Definition: The "local" region is defined by a distance metric which might not be ideal for all data types
  • Linear Approximation: Using a linear model for the local approximation might not capture complex local behaviors
