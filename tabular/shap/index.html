SHAP (SHapley Additive exPlanations)¶

The SHAP explainer in the XAI Toolbox implements the KernelSHAP algorithm, which uses game theory concepts to explain machine learning model predictions. SHAP values provide a unified measure of feature importance based on Shapley values.

Theory¶

SHAP values are based on Shapley values from cooperative game theory, which fairly distribute the "contribution" of each feature to the prediction. The SHAP value of a feature represents its contribution to the prediction, considering all possible combinations ("coalitions") of features.

Key properties of SHAP values include:

  • Local Accuracy: The sum of SHAP values equals the difference between the model's prediction and the average prediction.
  • Missingness: Features with zero SHAP values don't impact the prediction.
  • Consistency: If a model changes so that a feature's contribution increases, its SHAP value also increases.

Implementation¶

The Shap class implements the KernelSHAP algorithm, which is model-agnostic (works with any model type). This implementation leverages PyTorch data loaders and works with both classification and regression models.

Usage¶

Initialization¶

from chemxai.explainers import Shap

explainer = Shap(model, train_loader, test_loader, device)

Parameters: - model: The model to be explained. - train_loader: Training DataLoader to obtain background data. - test_loader: Test DataLoader for explanations. - device: Device (CPU or GPU) for operations.

Local Explanation¶

Get feature importance for a specific instance:

local_explanation = explainer.local_explanation(index=0)
print(local_explanation)

This returns a DataFrame with feature indices and their SHAP values for the specified instance, sorted by importance.

Global Explanation¶

Get feature importance across all instances:

all_local_importances, global_feature_importance = explainer.global_explanation()
print(global_feature_importance.head())

This returns: - all_local_importances: DataFrame with SHAP values for each feature across all instances. - global_feature_importance: DataFrame with average feature importance across all instances.

Example¶

import torch
import pandas as pd
import matplotlib.pyplot as plt
from chemxai.explainers import Shap

# Assume model and data loaders are defined
explainer = Shap(model, train_loader, test_loader, device)

# Get local explanation for a specific instance
local_exp = explainer.local_explanation(index=0)

# Plot top 10 features for this instance
plt.figure(figsize=(10, 6))
plt.barh(local_exp['Feature Index'][:10], local_exp['SHAP Value'][:10])
plt.xlabel('SHAP Value')
plt.ylabel('Feature Index')
plt.title('Top 10 Features for Instance #0')
plt.tight_layout()
plt.show()

# Get global explanation
_, global_exp = explainer.global_explanation()

# Plot top 10 features globally
plt.figure(figsize=(10, 6))
plt.barh(global_exp['Feature'][:10], global_exp['Importance'][:10])
plt.xlabel('Mean |SHAP Value|')
plt.ylabel('Feature')
plt.title('Top 10 Features Globally')
plt.tight_layout()
plt.show()

Limitations¶

  • Computation: KernelSHAP can be computationally expensive for large datasets or complex models.
  • Background Data: Results depend on the chosen background dataset (from train_loader).
  • Feature Independence: KernelSHAP assumes feature independence, which might not hold for all datasets.
