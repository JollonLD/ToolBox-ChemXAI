Node Graph LIME¶

Node Graph LIME adapts the LIME (Local Interpretable Model-agnostic Explanations) technique to graph neural networks at the node level. It provides feature importance values that show how each node and feature contribute to a specific node's prediction by approximating the model's local decision boundary.

Theory¶

Node Graph LIME builds on the original LIME framework to explain GNN predictions by perturbing node features and observing how predictions change. It utilizes kernel-based similarity functions to identify which features of a node and its neighbors are most influential for a model's prediction.

Key concepts: - Perturbation-based sampling: Generating variations of the input by perturbing features - Kernel weighting: Weighting samples based on their proximity to the original input - Local linear approximation: Using a simpler model (e.g., Lasso regression) to approximate the complex model locally - PCA dimensionality reduction: Reducing feature space complexity for more stable explanations

Implementation¶

The NodeGrapLIME class in this toolbox provides an implementation that: 1. Extracts a k-hop subgraph around the target node 2. Computes kernels for the feature space and prediction space 3. Performs dimensionality reduction using PCA 4. Uses LassoLars regression to approximate the local model behavior 5. Returns feature importance values and top features for each class

Usage¶

Initialization¶

from chemxai.explainers import NodeGrapLIME

explainer = NodeGrapLIME(
    data=data,
    model=model,
    device=device,
    gpu=False,  # Set to True for GPU acceleration
    hop=2,      # Number of hops for subgraph extraction
    rho=0.1     # Regularization parameter for Lasso regression
)

Parameters: - data: The graph data containing node features and edge indices - model: The trained GNN model to be explained - device: The device to run the model (CPU or GPU) - gpu: Whether to use GPU acceleration for model inference - hop: The number of hops for extracting the subgraph around the node of interest - rho: Regularization parameter for Lasso regression - cached: Whether to cache the model's predictions for efficiency

Explaining Predictions¶

explanation = explainer.explain(
    node_index=target_node,
    hops=2,
    num_samples=100,
    multiclass=False
)

Parameters: - node_index: The index of the node for which the explanation is generated - hops: The number of hops to consider in the neighborhood - num_samples: Number of samples to use for explanation generation - multiclass: Whether the model is a multiclass classifier

Returns: - A dictionary containing coef_pca, coef_original, and top_features

Example¶

import torch
import numpy as np
import matplotlib.pyplot as plt
from torch_geometric.data import Data
from chemxai.explainers import NodeGrapLIME

# Assume you have a trained GNN model and graph data
model = YourGNNModel()
data = Data(x=node_features, edge_index=edge_index)
device = torch.device("cuda" if torch.cuda.is_available() else "cpu")

# Initialize Node Graph LIME
explainer = NodeGrapLIME(
    data=data,
    model=model,
    device=device,
    gpu=torch.cuda.is_available(),
    hop=2,
    rho=0.1
)

# Explain prediction for a target node
target_node = 0
explanation = explainer.explain(
    node_index=target_node,
    hops=2,
    num_samples=100
)

# Extract feature importance values
coef_original = explanation["coef_original"]  # Shape: (num_features, num_classes)
top_features = explanation["top_features"][0]  # Top features for class 0

# Visualize feature importance
plt.figure(figsize=(10, 6))
plt.bar(range(len(top_features)), [coef_original[i, 0] for i in top_features])
plt.xlabel('Top Feature Index')
plt.ylabel('Coefficient Value')
plt.title(f'Feature Importance for Node {target_node}')
plt.tight_layout()
plt.show()

print(f"Top 5 important features: {top_features}")
print(f"Their coefficient values: {[coef_original[i, 0] for i in top_features]}")

Visualizing Node Neighborhood¶

To visualize the neighborhood with feature importance:

from torch_geometric.utils import k_hop_subgraph
import networkx as nx
import matplotlib.pyplot as plt

# Get k-hop subgraph around the target node
subset, sub_edge_index, mapping, _ = k_hop_subgraph(
    node_idx=target_node,
    num_hops=2,
    edge_index=data.edge_index,
    relabel_nodes=True,
    num_nodes=data.num_nodes
)

# Create networkx graph from the subgraph
G = nx.Graph()
edge_list = sub_edge_index.t().tolist()
G.add_edges_from(edge_list)

# Calculate importance for each node in the subgraph
node_importance = np.zeros(len(subset))
for node_idx, orig_idx in enumerate(subset):
    if node_idx < len(coef_original):
        # Sum absolute coefficients for all features of this node
        node_importance[node_idx] = np.sum(np.abs(coef_original[node_idx]))

# Plot the graph
plt.figure(figsize=(8, 8))
pos = nx.spring_layout(G)
nx.draw_networkx_edges(G, pos)
nx.draw_networkx_nodes(G, pos, 
                      node_color=node_importance,
                      cmap='coolwarm',
                      node_size=300)
nx.draw_networkx_labels(G, pos)
plt.colorbar(plt.cm.ScalarMappable(cmap='coolwarm'))
plt.title(f'Node Importance for Node {target_node}')
plt.axis('off')
plt.tight_layout()
plt.show()

Advanced Usage: Feature Contribution Analysis¶

For a deeper understanding of how specific features contribute to predictions:

import seaborn as sns

# Extract feature contribution for a specific class
class_idx = 0  # Change this to the class you're interested in
feature_importance = coef_original[:, class_idx]

# Get original feature names if available
feature_names = [f"Feature {i}" for i in range(len(feature_importance))]

# Create sorted importance visualization
sorted_indices = np.argsort(feature_importance)[::-1][:10]  # Top 10 features
plt.figure(figsize=(12, 6))
sns.barplot(x=[feature_names[i] for i in sorted_indices], 
            y=feature_importance[sorted_indices])
plt.xticks(rotation=45, ha='right')
plt.title(f'Top 10 Feature Contributions for Class {class_idx}')
plt.tight_layout()
plt.show()

Advantages and Limitations¶

Advantages¶

  • Model-agnostic: Works with any GNN architecture without requiring access to internal states
  • Interpretable: Uses linear models to approximate local decision boundaries
  • Fast approximation: More computationally efficient than methods that require exhaustive sampling
  • Dimensionality reduction: PCA helps manage high-dimensional feature spaces effectively

Limitations¶

  • Linear approximation: May not capture highly non-linear decision boundaries accurately
  • Neighborhood definition: Results depend on choosing an appropriate neighborhood size
  • Stability: Results can vary with different random samples
  • Memory requirements: Processing large graphs can be memory intensive
  • Kernel selection: Performance depends on appropriate kernel selection
