GNN Explainer¶

The GNN Explainer is a model-specific approach for explaining predictions of Graph Neural Networks (GNNs). It identifies the most important nodes, edges, and features that contribute to the model's prediction for a specific node.

Theory¶

GNN Explainer works by learning feature masks and edge masks that maximize the mutual information between the original prediction and the prediction from the masked graph. It optimizes these masks using gradient descent to identify the minimal subgraph and feature set that preserves the prediction.

Key concepts: - Node feature mask: Identifies important node features - Edge mask: Identifies important edges in the node's neighborhood - Mutual information maximization: Ensures that the explanation preserves the model's prediction

Implementation¶

The GNNExplain class in this toolbox leverages the PyTorch Geometric's GNNExplainer implementation, providing an easy-to-use interface compatible with various GNN architectures.

Usage¶

Initialization¶

from chemxai.explainers import GNNExplain

explainer = GNNExplain(
    model=model,
    device=device,
    data=data,
    epochs=100,
    mode='regression',  # or 'classification'
    task_level='node',  # or 'graph'
    return_type='raw'   # or 'probabilities'
)

Parameters: - model: The trained GNN model to be explained - device: The device to run the model (CPU or GPU) - data: The graph data containing node features and edge indices - epochs: Number of epochs for training the explainer - mode: The type of prediction task ('regression' or 'classification') - task_level: Whether the explanation is at the node level or graph level - return_type: The format of the returned explanation

Explaining Predictions¶

node_mask, prediction = explainer.explain(index=target_node)

Parameters: - index: The index of the node for which the explanation is generated

Returns: - node_mask: A list of feature importances for each node feature - prediction: The predicted value for the specified node

Example¶

import torch
import numpy as np
import matplotlib.pyplot as plt
from torch_geometric.data import Data
from chemxai.explainers import GNNExplain

# Assume you have a trained GNN model and graph data
model = YourGNNModel()
data = Data(x=node_features, edge_index=edge_index)
device = torch.device("cuda" if torch.cuda.is_available() else "cpu")

# Initialize GNN Explainer
explainer = GNNExplain(
    model=model,
    device=device,
    data=data,
    epochs=100,
    mode='regression',
    task_level='node'
)

# Explain prediction for a target node
target_node = 0
node_mask, prediction = explainer.explain(index=target_node)

# Visualize feature importance
plt.figure(figsize=(10, 6))
plt.bar(range(len(node_mask)), node_mask)
plt.xlabel('Feature Index')
plt.ylabel('Importance')
plt.title(f'Feature Importance for Node {target_node} (Pred: {prediction:.4f})')
plt.tight_layout()
plt.show()

# Get top-5 important features
top_features = np.argsort(node_mask)[::-1][:5]
print(f"Top 5 important features: {top_features}")
print(f"Their importance values: {[node_mask[i] for i in top_features]}")

Visualizing Explanations¶

To visualize the subgraph with highlighted important nodes and edges:

from torch_geometric.utils import k_hop_subgraph
from torch_geometric.data import Data
import networkx as nx

# Get k-hop subgraph around the target node
subset, sub_edge_index, mapping, _ = k_hop_subgraph(
    node_idx=target_node,
    num_hops=2,
    edge_index=data.edge_index,
    relabel_nodes=True
)

# Create networkx graph from the subgraph
G = nx.Graph()
edge_list = sub_edge_index.t().tolist()
G.add_edges_from(edge_list)

# Map node importance from node_mask to the subgraph nodes
node_importance = node_mask

# Plot the graph with node importance
plt.figure(figsize=(8, 8))
pos = nx.spring_layout(G)
nx.draw_networkx_edges(G, pos)
nx.draw_networkx_nodes(G, pos, 
                      node_color=node_importance,
                      cmap='viridis',
                      node_size=300)
nx.draw_networkx_labels(G, pos)
plt.colorbar(plt.cm.ScalarMappable(cmap='viridis'))
plt.title(f'Node Importance for Node {target_node}')
plt.axis('off')
plt.tight_layout()
plt.show()

Limitations¶

  • Computational Cost: Training the explainer can be computationally expensive for large graphs
  • Local Explanations: GNN Explainer provides local explanations for specific nodes, not global model insights
  • Hyperparameter Sensitivity: Results may vary based on the number of epochs and other hyperparameters
  • Edge Explanations: The current implementation focuses mainly on node feature masks rather than edge masks
