Node Graph SHAP¶

Node Graph SHAP adapts the SHAP (SHapley Additive exPlanations) method to graph neural networks at the node level. It provides theoretically grounded feature importance values that show how each feature contributes to a specific node's prediction.

Theory¶

Node Graph SHAP is based on Shapley values from cooperative game theory, which provide a fair way to distribute the contribution of each feature to the prediction. It considers both node features and topological information to determine their respective contributions to a specific node's prediction.

Key concepts: - Shapley values: A method from game theory that fairly allocates contributions among features - Permutation sampling: Estimating Shapley values by sampling different feature combinations - Weighted least squares: Using kernel weighting to approximate Shapley values efficiently

Implementation¶

The NodeGraphSHAP class in this toolbox provides an implementation that: 1. Samples different combinations of feature presence 2. Weights samples based on the Shapley kernel formula 3. Uses weighted linear regression to estimate feature importance 4. Returns Shapley values for each feature as importance scores

Usage¶

Initialization¶

from chemxai.explainers import NodeGraphSHAP

explainer = NodeGraphSHAP(
    data=data,
    model=model,
    device=device,
    gpu=False  # Set to True for GPU acceleration
)

Parameters: - data: The graph data containing node features and edge indices - model: The trained GNN model to be explained - device: The device to run the model (CPU or GPU) - gpu: Whether to use GPU acceleration for model inference

Explaining Predictions¶

explanation = explainer.explain(
    node_index=target_node,
    hops=2,
    num_samples=50,
    multiclass=False
)

Parameters: - node_index: The index of the node for which the explanation is generated - hops: The number of hops to consider in the neighborhood - num_samples: Number of samples to use for Shapley value estimation - multiclass: Whether the model is a multiclass classifier

Returns: - A dictionary containing shap_values, top_features, and top_values

Example¶

import torch
import numpy as np
import matplotlib.pyplot as plt
from torch_geometric.data import Data
from chemxai.explainers import NodeGraphSHAP

# Assume you have a trained GNN model and graph data
model = YourGNNModel()
data = Data(x=node_features, edge_index=edge_index)
device = torch.device("cuda" if torch.cuda.is_available() else "cpu")

# Initialize Node Graph SHAP
explainer = NodeGraphSHAP(
    data=data,
    model=model,
    device=device,
    gpu=torch.cuda.is_available()
)

# Explain prediction for a target node
target_node = 0
explanation = explainer.explain(
    node_index=target_node,
    hops=2,
    num_samples=50
)

# Extract Shapley values for each feature
shap_values = explanation["shap_values"]
top_features = explanation["top_features"][0]  # Top features for class 0
top_values = explanation["top_values"][0]      # Values for top features

# Visualize feature importance
plt.figure(figsize=(10, 6))
plt.bar(range(len(top_features)), top_values)
plt.xlabel('Top Feature Index')
plt.ylabel('SHAP Value')
plt.title(f'Feature Importance for Node {target_node}')
plt.tight_layout()
plt.show()

print(f"Top 5 important features: {top_features[:5]}")
print(f"Their SHAP values: {top_values[:5]}")

Visualizing Node Importance¶

To visualize the neighborhood with node importance:

from torch_geometric.utils import k_hop_subgraph
import networkx as nx

# Get k-hop subgraph around the target node
subset, sub_edge_index, mapping, _ = k_hop_subgraph(
    node_idx=target_node,
    num_hops=2,
    edge_index=data.edge_index,
    relabel_nodes=True,
    num_nodes=data.num_nodes
)

# Create networkx graph from the subgraph
G = nx.Graph()
edge_list = sub_edge_index.t().tolist()
G.add_edges_from(edge_list)

# Calculate importance for each node in the subgraph
# This is just an example - you might need to adapt to your specific case
node_importance = np.zeros(len(subset))
for node_idx, orig_idx in enumerate(subset):
    if node_idx < len(shap_values):
        node_importance[node_idx] = np.sum(np.abs(shap_values[node_idx]))

# Plot the graph
plt.figure(figsize=(8, 8))
pos = nx.spring_layout(G)
nx.draw_networkx_edges(G, pos)
nx.draw_networkx_nodes(G, pos, 
                      node_color=node_importance,
                      cmap='viridis',
                      node_size=300)
nx.draw_networkx_labels(G, pos)
plt.colorbar(plt.cm.ScalarMappable(cmap='viridis'))
plt.title(f'Node Importance for Node {target_node}')
plt.axis('off')
plt.tight_layout()
plt.show()

Advantages and Limitations¶

Advantages¶

  • Solid theoretical foundation: Based on game theory with strong mathematical backing
  • Feature interactions: Captures interactions between features naturally
  • Model-agnostic: Works with any GNN architecture without requiring access to internal states

Limitations¶

  • Computational complexity: Computing exact Shapley values is NP-hard, requiring approximation
  • Sample efficiency: May need many samples for accurate estimates, especially with high-dimensional features
  • Local explanations: Provides explanations for individual predictions, not global model behavior
  • Memory requirements: Processing large graphs can be memory intensive

References¶

  • Original SHAP paper - Lundberg and Lee, "A Unified Approach to Interpreting Model Predictions"
  • KernelSHAP - Lundberg and Lee, "Consistent Individualized Feature Attribution for Tree Ensembles"
