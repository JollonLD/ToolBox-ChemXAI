Graph SHAP¶

Graph SHAP adapts the SHAP (SHapley Additive exPlanations) method to graph neural networks at the graph level. It provides theoretically grounded feature importance values that show how each feature contributes to the overall graph prediction.

Theory¶

Graph SHAP is based on Shapley values from cooperative game theory, which provide a fair way to distribute the contribution of each feature to the prediction. It measures how the prediction changes when specific features are included or excluded, averaging over all possible feature combinations.

Key concepts: - Shapley values: A method from game theory for fair attribution of contributions - Binary feature masking: Turning features on or off across the entire graph - Weighted least squares: Solving for Shapley values using weighted regression - Kernel weighting: Special weight function that emphasizes certain feature combinations

Implementation¶

The GraphSHAP class in this toolbox provides an implementation that: 1. Samples different combinations of feature presence across the graph 2. Weights samples based on the Shapley kernel formula 3. Uses weighted linear regression (OLS) to estimate feature importance 4. Returns Shapley values for each feature as importance scores

Usage¶

Initialization¶

from chemxai.explainers import GraphSHAP

explainer = GraphSHAP(
    data=data,
    model=model,
    device=device,
    gpu=False  # Set to True for GPU acceleration
)

Parameters: - data: The graph data containing node features and edge indices - model: The trained GNN model to be explained - device: The device to run the model (CPU or GPU) - gpu: Whether to use GPU acceleration for model inference

Explaining Predictions¶

explanation = explainer.explain(
    num_samples=30,
    info=True
)

Parameters: - num_samples: Number of samples to use for Shapley value estimation - info: Whether to return additional information about the explanation

Returns: - A dictionary containing shap_values, top_features, top_values, true_prediction, and base_value

Example¶

import torch
import numpy as np
import matplotlib.pyplot as plt
from torch_geometric.data import Data
from chemxai.explainers import GraphSHAP

# Assume you have a trained GNN model and graph data
model = YourGNNModel()
data = Data(x=node_features, edge_index=edge_index)
device = torch.device("cuda" if torch.cuda.is_available() else "cpu")

# Initialize Graph SHAP
explainer = GraphSHAP(
    data=data,
    model=model,
    device=device
)

# Explain prediction for the entire graph
explanation = explainer.explain(num_samples=50)

# Extract results
shap_values = explanation["shap_values"]
top_features = explanation["top_features"]
top_values = explanation["top_values"]
true_prediction = explanation["true_prediction"]
base_value = explanation["base_value"]

# Visualize top feature importance
plt.figure(figsize=(10, 6))
plt.bar(range(10), top_values[:10])  # Show top 10 features
plt.xlabel('Top Feature Index')
plt.ylabel('SHAP Value')
plt.title(f'Top 10 Feature Importance (Prediction: {true_prediction:.4f})')
plt.tight_layout()
plt.show()

print(f"Base value: {base_value:.4f}")
print(f"True prediction: {true_prediction:.4f}")
print(f"Top 5 important features: {top_features[:5]}")
print(f"Their SHAP values: {top_values[:5]}")

Visualizing Feature Importance¶

To visualize the overall feature importance:

import numpy as np
import matplotlib.pyplot as plt

# Create a full feature importance array (all features)
all_features_importance = np.zeros(data.num_features)
for i, idx in enumerate(top_features):
    if i < len(top_values):  # Safety check
        all_features_importance[idx] = top_values[i]

# Plot all features
plt.figure(figsize=(12, 6))
plt.bar(range(data.num_features), all_features_importance)
plt.xlabel('Feature Index')
plt.ylabel('SHAP Value')
plt.title('Feature Importance for Graph Prediction')
plt.axhline(y=0, color='r', linestyle='-', alpha=0.3)  # Zero line
plt.tight_layout()
plt.show()

# Optional: Plot SHAP values as a waterfall chart
# Subset to top 10 features for clarity
plt.figure(figsize=(12, 6))
plt.barh(range(10), top_values[:10])
plt.yticks(range(10), [f"Feature {idx}" for idx in top_features[:10]])
plt.xlabel('SHAP Value')
plt.ylabel('Feature')
plt.title('Top 10 Features Impact on Prediction')
plt.axvline(x=0, color='r', linestyle='-', alpha=0.3)  # Zero line
plt.tight_layout()
plt.show()

Advantages and Limitations¶

Advantages¶

  • Solid theoretical foundation: Based on game theory with strong mathematical backing
  • Feature interactions: Captures interactions between features naturally
  • Model-agnostic: Works with any GNN architecture without requiring access to internal states
  • Global explanation: Provides insight for the entire graph's prediction

Limitations¶

  • Computational complexity: Computing exact Shapley values is NP-hard, requiring approximation
  • Sample efficiency: May need many samples for accurate estimates, especially with high-dimensional features
  • Memory requirements: Processing large graphs can be memory intensive
  • Binary masking: Binary on/off perturbation may not be realistic for some features

References¶

  • Original SHAP paper - Lundberg and Lee, "A Unified Approach to Interpreting Model Predictions"
  • KernelSHAP - Lundberg and Lee, "Consistent Individualized Feature Attribution for Tree Ensembles"
