Graph Explainers Overview¶

The XAI Toolbox includes powerful explainers designed specifically for Graph Neural Networks (GNNs) and graph-structured data. These explainers help you understand how your GNN models make predictions by identifying important nodes, edges, and features in the graph.

Available Graph Explainers¶

The toolbox provides the following explainers for graph data:

  1. GNN Explainer: A model-specific explainer that identifies important nodes and edges for GNN predictions
  2. Node Graph LIME: Adaptation of LIME for explaining node-level predictions in graphs
  3. Node Graph SHAP: Adaptation of KernelSHAP for node-level predictions in graphs
  4. Graph LIME: Implementation of LIME for graph-level predictions
  5. Graph SHAP: Implementation of KernelSHAP for graph-level predictions

Types of Graph Explanations¶

Graph explainers generally provide two types of explanations:

  1. Node-level explanations: Explain predictions for individual nodes in a graph
  2. Which neighboring nodes influence this node's prediction?
  3. Which features of this node or its neighbors are important?

  4. Which edges affect the message passing for this node?

  5. Graph-level explanations: Explain predictions for entire graphs

  6. Which nodes are most important for the graph's overall prediction?
  7. Which features contribute most to the graph's classification?
  8. Which substructures in the graph drive the prediction?

Choosing the Right Graph Explainer¶

Explainer Level Approach Best For Computation
GNN Explainer Node Feature & Edge Mask Feature attribution Medium
Node Graph LIME Node Perturbation-based Neighborhood importance Medium
Node Graph SHAP Node Shapley values Feature importance with theoretical guarantees High
Graph LIME Graph Perturbation-based Quick graph-level explanations Medium
Graph SHAP Graph Shapley values Detailed graph-level importance High

When to use each explainer:¶

  • GNN Explainer: When you want to explain specific predictions in terms of node and edge importance
  • Node Graph LIME: When you need quick node-level explanations and feature importance
  • Node Graph SHAP: When you need theoretically sound node feature importance
  • Graph LIME: When you need to understand what drives graph-level predictions
  • Graph SHAP: When you want comprehensive and theoretically sound graph-level explanations

Common Usage Pattern¶

Most of the graph explainers follow a similar usage pattern:

  1. Initialize the explainer with your GNN model and graph data
  2. Call the explain method, specifying the node index for node-level explainers
  3. Analyze and visualize the resulting explanations
# Generic pattern for node-level explainers
explainer = NodeExplainer(model, device, data, additional_params)
explanation = explainer.explain(node_index=target_node)

# Generic pattern for graph-level explainers
explainer = GraphExplainer(model, device, data, additional_params)
explanation = explainer.explain()
