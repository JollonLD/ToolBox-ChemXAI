Graph LIME¶

Graph LIME is a model-agnostic approach for explaining predictions at the graph level. It adapts the LIME (Local Interpretable Model-agnostic Explanations) framework to graph-structured data, helping to understand which features contribute most to the overall graph prediction.

Theory¶

Graph LIME works by perturbing features across the entire graph and observing how these perturbations affect the model's prediction. It then trains a simple interpretable model (typically a linear model with Lasso regularization) on these perturbed instances to approximate the local behavior of the complex GNN model.

Key concepts: - Global perturbation: Creating variations of the graph's features while maintaining structure - Feature masking: Randomly masking features across all nodes in the graph - Surrogate model: Training an interpretable model to mimic the GNN's behavior - Feature importance: Weights of the surrogate model indicate the importance of each feature

Implementation¶

The GraphLIME class in this toolbox provides an implementation that: 1. Generates perturbed versions of the graph by applying random masks to node features 2. Gets predictions for these perturbed instances using the original GNN model 3. Trains a regularized linear model to approximate the GNN's behavior locally 4. Returns feature importances based on the linear model's coefficients

Usage¶

Initialization¶

from chemxai.explainers import GraphLIME

explainer = GraphLIME(
    model=model,
    device=device,
    rho=0.1  # Regularization parameter for Lasso regression
)

Parameters: - model: The trained GNN model to be explained - device: The device to run the model (CPU or GPU) - rho: Regularization parameter for Lasso regression

Explaining Predictions¶

explanation = explainer.explain(
    data=graph_data,
    num_samples=100
)

Parameters: - data: The graph data containing node features and edge indices - num_samples: Number of perturbed samples to generate

Returns: - A dictionary containing feature_importance, top_features, and coef_matrix

Example¶

import torch
import numpy as np
import matplotlib.pyplot as plt
from torch_geometric.data import Data
from chemxai.explainers import GraphLIME

# Assume you have a trained GNN model and graph data
model = YourGNNModel()
data = Data(x=node_features, edge_index=edge_index)
device = torch.device("cuda" if torch.cuda.is_available() else "cpu")

# Initialize Graph LIME
explainer = GraphLIME(
    model=model,
    device=device,
    rho=0.1
)

# Explain prediction for the entire graph
explanation = explainer.explain(
    data=data,
    num_samples=100
)

# Get feature importance and top features
feature_importance = explanation["feature_importance"]
top_features = explanation["top_features"]

# Visualize feature importance
plt.figure(figsize=(10, 6))
plt.bar(range(len(feature_importance)), feature_importance)
plt.xlabel('Feature Index')
plt.ylabel('Importance')
plt.title('Feature Importance for Graph Prediction')
plt.tight_layout()
plt.show()

# Print top-5 important features
print(f"Top 5 important features: {top_features[:5]}")
print(f"Their importance values: {feature_importance[top_features[:5]]}")

Visualizing Feature Importance Matrix¶

To visualize the importance of each feature across nodes:

import seaborn as sns

# Get coefficient matrix (node x feature)
coef_matrix = explanation["coef_matrix"]

# Plot heatmap of feature importance across nodes
plt.figure(figsize=(12, 10))
sns.heatmap(coef_matrix, cmap="viridis", annot=False)
plt.xlabel('Feature Index')
plt.ylabel('Node Index')
plt.title('Feature Importance Matrix')
plt.tight_layout()
plt.show()

# Alternative: Plot average importance per feature (bar chart)
avg_importance = coef_matrix.mean(axis=0)
plt.figure(figsize=(10, 6))
plt.bar(range(len(avg_importance)), avg_importance)
plt.xlabel('Feature Index')
plt.ylabel('Average Importance')
plt.title('Average Feature Importance Across All Nodes')
plt.tight_layout()
plt.show()

Advantages and Limitations¶

Advantages¶

  • Model-agnostic: Works with any GNN architecture without requiring access to internal states
  • Interpretable: Provides straightforward feature importance scores
  • Global view: Explains predictions at the graph level rather than individual nodes
  • Flexibility: Can be adapted for different types of graph data and prediction tasks

Limitations¶

  • Sampling variability: Results may vary between runs due to random perturbation
  • Linear approximation: Assumes the model's behavior can be approximated locally by a linear model
  • Feature independence: May not capture complex interactions between features effectively
  • Computation cost: Generating and evaluating many perturbed graphs can be computationally expensive
  • Binary masking: Simplistic perturbation approach may not reflect all possible feature variations
