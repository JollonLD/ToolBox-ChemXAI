Plots Module¶

Overview¶

The Plots Module provides visualization utilities for explainability analysis.

radar_plot()¶

Create radar plots to visualize feature importance from explanation methods.

Parameters¶

  • values (numpy.ndarray): Feature importance values
  • feature_names (list, optional): Names of features
  • title (str): Plot title

horizontal_bar_plot()¶

Create horizontal bar plots for feature importance visualization.

Parameters¶

  • values (numpy.ndarray): Feature importance values
  • feature_names (list, optional): Names of features
  • top_k (int, optional): Show only top K features

k_hop_subgraph()¶

Extract k-hop neighborhood subgraph around specified nodes.

Usage Example¶

from chemxai.plots import radar_plot, horizontal_bar_plot

# Visualize SHAP values
radar_plot(shap_values, feature_names=['C', 'H', 'O', 'N'])
horizontal_bar_plot(shap_values, top_k=10)
