Getting Started¶

This guide will help you get started with the XAI Toolbox by providing basic usage examples for both tabular and graph-based explainers.

Installation¶

First, install the toolbox using pip:

pip install chemxai

Required dependencies will be installed automatically, including:

  • numpy
  • pandas
  • torch
  • torch_geometric
  • shap
  • lime
  • scikit-learn

Basic Usage¶

Tabular Explainers¶

SHAP Example¶

import torch
import torch.nn as nn
from torch.utils.data import DataLoader, TensorDataset
from chemxai.explainers import Shap

# Assume you have a trained model and data loaders
model = YourModel()
train_loader = DataLoader(train_dataset, batch_size=32)
test_loader = DataLoader(test_dataset, batch_size=32)
device = torch.device("cuda" if torch.cuda.is_available() else "cpu")

# Initialize SHAP explainer
explainer = Shap(model, train_loader, test_loader, device)

# Get local explanation for a specific instance
local_explanation = explainer.local_explanation(index=0)
print(local_explanation)

# Get global explanation across all instances
all_local, global_importance = explainer.global_explanation()
print(global_importance.head())

LIME Example¶

from chemxai.explainers import LIME

# Initialize LIME explainer
explainer = LIME(model, train_loader, test_loader, device, mode='regression')

# Get local explanation for a specific instance
lime_explanation = explainer.local_explanation(index=0, num_features=10)
print(lime_explanation)

Graph Explainers¶

GNN Explainer Example¶

import torch
from torch_geometric.data import Data
from chemxai.explainers import GNNExplain

# Assume you have a trained GNN model and graph data
model = YourGNNModel()
data = Data(x=node_features, edge_index=edge_index)
device = torch.device("cuda" if torch.cuda.is_available() else "cpu")

# Initialize GNN Explainer
explainer = GNNExplain(
    model=model,
    device=device,
    data=data,
    epochs=100,
    mode='regression',
    task_level='node'
)

# Explain prediction for a specific node
node_mask, prediction = explainer.explain(index=0)
print(f"Prediction: {prediction}")
print(f"Top 5 important features: {sorted(range(len(node_mask)), key=lambda i: node_mask[i], reverse=True)[:5]}")

Node Graph LIME Example¶

from chemxai.explainers import NodeGrapLIME

# Initialize NodeGrapLIME explainer
explainer = NodeGrapLIME(
    data=data,
    model=model,
    device=device,
    hop=2,
    rho=0.1
)

# Explain prediction for a specific node
explanation = explainer.explain(node_index=0, hops=2, num_samples=100)
print("Top features per class:", explanation["top_features"])

Configuration Options¶

Most explainers allow you to configure various parameters:

  • Model parameters (model architecture, device)
  • Sampling parameters (number of samples, neighborhood size)
  • Algorithm-specific parameters (kernel width, regularization strength)

Refer to the specific documentation for each explainer to learn about all available options.
