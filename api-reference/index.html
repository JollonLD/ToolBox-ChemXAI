API Reference¶

This page provides detailed API reference for all the explainers included in the ChemXAI toolbox.

Tabular Explainers¶

SHAP¶

class Shap:
    def __init__(self, model, train_loader, test_loader, device)

    def local_explanation(self, index)

    def global_explanation()

Parameters:¶

  • __init__:
  • model: The trained model to be explained
  • train_loader: DataLoader with training data for background distribution
  • test_loader: DataLoader with test data for explanations

  • device: Device (CPU or GPU) for computations

  • local_explanation:

  • index: Index of the instance to explain

  • Returns: DataFrame with feature indices and SHAP values

  • global_explanation:

  • Returns: Tuple of DataFrames (all_local_importances, global_feature_importance)

LIME¶

class LIME:
    def __init__(self, model, train_loader, test_loader, device, mode='regression')

    def predict_fn(self, data)

    def local_explanation(self, index, num_features=None)

Parameters:¶

  • __init__:
  • model: The trained model to be explained
  • train_loader: DataLoader with training data
  • test_loader: DataLoader with test data for explanations
  • device: Device (CPU or GPU) for computations

  • mode: 'regression' or 'classification'

  • predict_fn:

  • data: Input data for prediction

  • Returns: Model predictions as numpy array

  • local_explanation:

  • index: Index of the instance to explain
  • num_features: Number of features to include in explanation (default: all)
  • Returns: DataFrame with feature names and LIME values

Graph Explainers¶

GNN Explainer¶

class GNNExplain:
    def __init__(self, model, device, data, epochs, mode='regression', task_level='node', return_type='raw')

    def explain(self, index)

Parameters:¶

  • __init__:
  • model: The trained GNN model to be explained
  • device: Device (CPU or GPU) for computations
  • data: Graph data containing node features and edge indices
  • epochs: Number of epochs for training the explainer
  • mode: 'regression' or 'classification'
  • task_level: 'node' or 'graph'

  • return_type: 'raw' or 'probabilities'

  • explain:

  • index: Index of the node to explain
  • Returns: Tuple of (node_mask, prediction)

Node Graph LIME¶

class NodeGrapLIME:
    def __init__(self, data, model, device, gpu=False, hop=2, rho=0.1, cached=True)

    def explain(self, node_index, hops, num_samples, info=False, multiclass=False, *unused, **kwargs)

Parameters:¶

  • __init__:
  • data: Graph data containing node features and edge indices
  • model: The trained GNN model to be explained
  • device: Device (CPU or GPU) for computations
  • gpu: Whether to use GPU acceleration
  • hop: Number of hops for the subgraph
  • rho: Regularization parameter for Lasso regression

  • cached: Whether to cache model predictions

  • explain:

  • node_index: Index of the node to explain
  • hops: Number of hops to consider for the subgraph
  • num_samples: Number of samples to generate
  • info: Whether to return additional information
  • multiclass: Whether the model is a multiclass classifier
  • Returns: Dictionary with coef_pca, coef_original, and top_features

Node Graph SHAP¶

class NodeGraphShap:
    def __init__(self, data, model, device, gpu=False)

    def explain(self, node_index=0, hops=2, num_samples=10, info=True, multiclass=False, *unused)

Parameters:¶

  • __init__:
  • data: Graph data containing node features and edge indices
  • model: The trained GNN model to be explained
  • device: Device (CPU or GPU) for computations

  • gpu: Whether to use GPU acceleration

  • explain:

  • node_index: Index of the node to explain (default: 0)
  • hops: Number of hops to consider for the subgraph (default: 2)
  • num_samples: Number of samples to generate (default: 10)
  • info: Whether to return additional information (default: True)
  • multiclass: Whether the model is a multiclass classifier (default: False)
  • Returns: Dictionary with shap_values, top_features, and top_values

Graph LIME¶

class GraphLIME:
    def __init__(self, model, device='cpu', rho=0.1)

    def explain(self, data, num_samples=100)

Parameters:¶

  • __init__:
  • model: The trained GNN model to be explained
  • device: Device (CPU or GPU) for computations (default: 'cpu')

  • rho: Regularization parameter for Lasso regression (default: 0.1)

  • explain:

  • data: Graph data containing node features and edge indices
  • num_samples: Number of samples to generate (default: 100)
  • Returns: Dictionary with feature_importance, top_features, and coef_matrix

Graph SHAP¶

class GraphShap:
    def __init__(self, data, model, device=None, gpu=False)

    def explain(self, num_samples=30, info=True)

Parameters:¶

  • __init__:
  • data: Graph data containing node features and edge indices
  • model: The trained GNN model to be explained
  • device: Device (CPU or GPU) for computations (default: None)

  • gpu: Whether to use GPU acceleration (default: False)

  • explain:

  • num_samples: Number of samples to generate (default: 30)
  • info: Whether to return additional information (default: True)
  • Returns: Dictionary with shap_values, top_features, top_values, true_prediction, and base_value

Utility Functions¶

k_hop_subgraph¶

def k_hop_subgraph(node_idx, num_hops, edge_index, relabel_nodes=False, num_nodes=None, flow='source_to_target')

Parameters:¶

  • node_idx: The central node index
  • num_hops: The number of hops to consider
  • edge_index: Edge indices of the graph
  • relabel_nodes: Whether to relabel nodes in the subgraph
  • num_nodes: Total number of nodes in the graph
  • flow: The message passing flow direction ('source_to_target' or 'target_to_source')
  • Returns: Tuple of (subset, sub_edge_index, mapping, edge_mask)
