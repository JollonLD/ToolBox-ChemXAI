Explainers Module

Overview

The Explainers module (explainers.py) provides a comprehensive suite of explanation methods for both tabular and graph-based molecular models. It includes implementations of SHAP, LIME, GNNExplainer, and specialized graph explanation methods.

Module Structure

All explainers are implemented in a single file: chemxai/explainers.py (909 lines)

Tabular Explainers

Class: Shap

SHAP (SHapley Additive exPlanations) explainer for tabular molecular data using Kernel SHAP.

Initialization

from chemxai.explainers import Shap

explainer = Shap(
    model=model,
    background_tensor=background_data,
    test_tensor=test_data,
    device=device
)

Parameters:

Parameter Type Description
model torch.nn.Module Trained PyTorch model
background_tensor torch.Tensor Background data for SHAP baseline
test_tensor torch.Tensor Test data to explain
device torch.device Computation device (CPU/GPU)

Methods

explain_local(index)

Generate SHAP values for a single instance.

shap_values = explainer.explain_local(index=0)
  • Parameters: index (int) - Index of instance to explain
  • Returns: list of SHAP values for each feature

explain_global()

Generate global feature importance across all test instances.

global_importance = explainer.explain_global()
  • Returns: list of mean absolute SHAP values per feature

Class: LIME

LIME (Local Interpretable Model-agnostic Explanations) for tabular data.

Initialization

from chemxai.explainers import LIME

explainer = LIME(
    model=model,
    background_tensor=background_data,
    test_tensor=test_data,
    device=device,
    mode='regression'
)

Parameters:

Parameter Type Default Description
model torch.nn.Module - Trained model
background_tensor torch.Tensor - Training data
test_tensor torch.Tensor - Test data
device torch.device - Device
mode str 'regression' 'regression' or 'classification'

Methods

explain_local(index, num_features=None)

lime_values = explainer.explain_local(index=0, num_features=10)
  • Parameters: index (int), num_features (int, optional)
  • Returns: list of LIME importance values

Graph Explainers

Native GNN explanation using edge and node masking.

Initialization

    model=model,

)

Parameters:

Parameter Type Default Description

device torch.device - Computation device
data Data - PyG graph data
epochs int 100 Training epochs for masks
mode str 'regression' Task type
task_level str 'graph' 'graph' or 'node'
return_type str 'raw' 'raw' or 'probabilities'

Methods

explain(index=None)

node_mask, edge_mask, explanation = explainer.explain()
  • Returns: tuple of (node_mask, edge_mask, full_explanation)

Complete Usage Examples

Tabular Model Explanation

import torch
from chemxai.data import qm9_tabular
from chemxai.models import MLP
from chemxai.explainers import Shap, LIME

# Load data
qm9 = qm9_tabular()
train_loader, _, test_loader, _, _, _, _ = qm9.get_paired_dataloaders_tabular(
    batch_size=32, descriptor_type='Morgan'
)

# Get data batches
bg_data = next(iter(train_loader))[0]
test_data = next(iter(test_loader))[0]

# Initialize explainers
shap_explainer = Shap(model, bg_data, test_data, device)
lime_explainer = LIME(model, bg_data, test_data, device)

# Generate explanations
shap_local = shap_explainer.explain_local(0)
shap_global = shap_explainer.explain_global()
lime_local = lime_explainer.explain_local(0)

Graph Model Explanation

from chemxai.data import graph_datasets
from chemxai.models import GCN
from chemxai.explainers import GNNExplain, GraphShap, GraphLIME

# Load graph data
qm9_graph = graph_datasets(dataset_name='QM9')
train_loader, _, test_loader = qm9_graph.prepare_data_graph(
    target=7, batch_size=32
)

# Get a graph
graph = next(iter(test_loader))

# GNNExplainer
gnn_explainer = GNNExplain(model, device, graph, epochs=100)
node_mask, edge_mask, _ = gnn_explainer.explain()

# GraphShap
graph_shap = GraphShap(graph, model, device)
shap_values = graph_shap.explain(num_samples=30)

# GraphLIME
graph_lime = GraphLIME(model, device='cpu')
lime_values = graph_lime.explain(graph, num_samples=100)

Node-Level Explanation

from chemxai.explainers import NodeGraphShap, NodeGrapLIME

# Node-level SHAP
node_shap = NodeGraphShap(graph, model, device)
node_explanation = node_shap.explain(
    node_index=0, 
    hops=2, 
    num_samples=30
)

# Node-level LIME
node_lime = NodeGrapLIME(graph, model, device, hop=2)
node_lime_exp = node_lime.explain(
    node_index=0,
    hops=2,
    num_samples=30
)

Comparison Guide

When to Use Each Explainer

Explainer Best For Pros Cons
SHAP Tabular, feature attribution Theoretically grounded, global view Slower computation
LIME Tabular, local explanations Fast, interpretable Less stable
GNNExplain Graph, native GNN method Model-aware, edge/node masks Requires training
GraphShap Graph-level predictions Theoretically sound Computationally expensive
GraphLIME Graph-level, fast Faster than GraphShap Approximation-based
NodeGraphShap Node-level predictions Principled, local context Slower for large graphs
NodeGrapLIME Node-level, faster Quick local explanations Less rigorous

Technical Details

Shapley Values

  • Based on cooperative game theory
  • Measures marginal contribution of each feature
  • Satisfies desirable properties: efficiency, symmetry, dummy, additivity

LIME Methodology

  • Generates perturbations around instance
  • Fits interpretable model (linear) locally
  • Uses Lasso for feature selection

GNNExplainer Approach

  • Learns masks via gradient descent
  • Maximizes mutual information
  • Applies entropy regularization

Subgraph Extraction

  • Node-level explainers extract k-hop neighborhoods
  • Preserves local graph structure
  • Relabels nodes for consistency

Best Practices

Choosing Parameters

  • num_samples: 30-100 for SHAP, 100-500 for LIME
  • hops: 2-3 for node-level explanations
  • epochs (GNNExplain): 100-200 for convergence
  • rho (LIME): 0.1-0.5 for Lasso regularization

Interpretation Tips

  • Compare multiple explainers for robustness
  • Visualize results using plots module
  • Validate against domain knowledge
  • Consider explanation stability across similar instances

Performance Optimization

  • Use GPU for GNN explainers when available
  • Cache background data for multiple explanations
  • Adjust sample size based on accuracy needs
  • Use smaller subgraphs for faster node-level explanations
