Explainers Module - 100% Code Coverage (7 Classes)¶

Overview¶

Complete explainability toolkit with 2 tabular and 5 graph explainers. All methods, parameters, and usage patterns documented.

Tabular Explainers¶

1. Shap - KernelSHAP¶

__init__(model, background_tensor, test_tensor, device)

Parameters:

  • model: Trained model
  • background_tensor (torch.Tensor): Training/background data
  • test_tensor (torch.Tensor): Test data to explain
  • device (torch.device): CPU or CUDA

Methods:

  • explain_local(index) → list: SHAP values for instance at index
  • explain_global() → list: Mean absolute SHAP values (global importance)

2. LIME - Local Interpretable Model-agnostic Explanations¶

__init__(model, background_tensor, test_tensor, device, mode='regression')

Parameters:

  • model: Trained model
  • background_tensor: Training data
  • test_tensor: Test data
  • device: Device
  • mode (str): 'regression' or 'classification'. Default: 'regression'

Methods:

  • explain_local(index, num_features=None) → list: LIME importance values. If num_features=None, uses all features.

Graph Explainers¶

3. GNNExplain¶

__init__(model, device, data, epochs, mode='regression', task_level='graph', return_type='raw')

Parameters:

  • model (torch.nn.Module): Trained GNN
  • device: Device
  • data (torch_geometric.data.Data): Graph data
  • epochs (int): Training epochs for explainer
  • mode (str): 'regression' or 'classification'
  • task_level (str): 'node' or 'graph'
  • return_type (str): 'raw' or 'probabilities'

Methods:

  • explain(index=None) → tuple: (node_mask, edge_mask, explanation_object)
    • node_mask: Importance scores for each node
    • edge_mask: Importance scores for each edge

4. NodeGraphLIME¶

__init__(data, model, device, gpu=False, hop=2, rho=0.1, cached=True)

Parameters:

  • data: Graph data
  • model: GNN model
  • device: Device
  • gpu (bool): Use GPU. Default: False
  • hop (int): K-hop subgraph extraction. Default: 2
  • rho (float): Lasso regularization. Default: 0.1
  • cached (bool): Cache predictions. Default: True

Methods:

  • explain(node_index, hops, num_samples, info=False, multiclass=False) → list: Feature importance coefficients for node prediction

5. NodeGraphShap¶

__init__(data, model, device, gpu=False)

Parameters:

  • data: Graph data
  • model: GNN model
  • device: Device
  • gpu (bool): Use GPU

Methods:

  • explain(node_index=0, hops=2, num_samples=10, info=True, multiclass=False) → list: Shapley values for node features

6. GraphLIME¶

__init__(model, device='cpu', rho=0.1)

Parameters:

  • model: GNN model
  • device (torch.device): Device. Default: 'cpu'
  • rho (float): Lasso regularization. Default: 0.1

Methods:

  • explain(data, num_samples=100) → list: Feature importance for entire graph
    • data (torch_geometric.data.Data): Graph to explain
    • num_samples (int): Number of perturbed graphs. Default: 100

7. GraphShap¶

__init__(data, model, device=None, gpu=False)

Parameters:

  • data: Graph data
  • model: GNN model
  • device: Device (auto-detected if None)
  • gpu (bool): Use GPU

Methods:

  • explain(num_samples=30, info=True) → list: SHAP values for graph-level prediction
    • num_samples (int): Binary samples for Shapley kernel. Default: 30

Complete Usage Examples¶

Tabular SHAP¶

from chemxai.explainers import Shap

explainer = Shap(trained_model, train_features, test_features, device)
local_shap = explainer.explain_local(0)  # Instance 0
global_importance = explainer.explain_global()

Tabular LIME¶

from chemxai.explainers import LIME

lime = LIME(model, train_data, test_data, device, mode='regression')
lime_values = lime.explain_local(index=5, num_features=20)  # Top 20 features

GNN Explainer¶

from chemxai.explainers import GNNExplain

gnn_exp = GNNExplain(gcn_model, device, graph_data, epochs=200, task_level='graph')
node_importance, edge_importance, explanation = gnn_exp.explain(index=0)

# Visualize top nodes/edges
import numpy as np
top_nodes = np.argsort(node_importance)[-10:]
top_edges = np.argsort(edge_importance)[-10:]

Node-Level LIME¶

from chemxai.explainers import NodeGraphLIME

node_lime = NodeGraphLIME(graph_data, gnn_model, device, hop=2)
coefficients = node_lime.explain(node_index=10, hops=2, num_samples=50)

Graph-Level SHAP¶

from chemxai.explainers import GraphShap

graph_shap = GraphShap(graph_data, gnn_model, device, gpu=True)
shap_values = graph_shap.explain(num_samples=50)

# Top features
import numpy as np
feature_importance = np.abs(shap_values)
top_features_idx = np.argsort(feature_importance)[::-1][:15]

Best Practices¶

  • SHAP: Use smaller background sets (100-500 samples) for speed
  • LIME: Increase num_samples (1000+) for stability
  • GNNExplain: Train for 100-200 epochs; more for complex graphs
  • Node methods: Adjust hop parameter based on graph connectivity
  • Graph methods: Use num_samples=30-100 for good approximation
  • GPU: Enable for large graphs or many samples
