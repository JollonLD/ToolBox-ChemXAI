chemxai.explainers¶

Model interpretation and explainability methods for both tabular and graph-based molecular models. Implements SHAP, LIME, and GNN-specific explanation techniques.

Tabular Explainers¶

Shap¶

class chemxai.explainers.Shap(model, background_tensor, test_tensor, device)

KernelSHAP explainer for computing Shapley values on tabular molecular descriptors. Shapley values quantify each feature's contribution to the prediction, satisfying desirable properties like efficiency, symmetry, and additivity.

Parameters:

  • model (torch.nn.Module) – Trained PyTorch model to explain
  • background_tensor (torch.Tensor) – Reference dataset used for marginalizing out features. Shape: (num_background, num_features). Typically uses training data subset (100-500 samples)
  • test_tensor (torch.Tensor) – Test instances to explain. Shape: (num_test, num_features)
  • device (torch.device) – Device for computations (torch.device('cpu') or torch.device('cuda'))

Methods:

explain_local(index)

Computes SHAP values for a single test instance.

Parameters:

  • index (int) – Index of test instance to explain

Returns: list – SHAP values for each feature, where positive values increase the prediction and negative values decrease it. Length equals num_features.

explain_global()

Computes global feature importance across all test instances.

Returns: list – Mean absolute SHAP values for each feature, representing average importance. Higher values indicate more important features.

Mathematical Background:

The Shapley value φ_i for feature i is defined as:

φ_i = Σ_{S⊆F\{i}} (|S|!(|F|-|S|-1)!)/(|F|!) [f(S∪{i}) - f(S)]

where F is the set of all features, S is a subset, and f(S) is the prediction using only features in S.

Example:

import torch
from chemxai.explainers import Shap
from chemxai.models import MLP
from chemxai.data import qm9_tabular

# Load data and model
loader = qm9_tabular(descriptor_type='ECFPs')
features, targets = loader.load_data(target_idx=7)

model = MLP(input_dim=2048, hidden_dims=[256, 128], output_dim=1)
# ... train model ...

device = torch.device('cuda' if torch.cuda.is_available() else 'cpu')
model.to(device)

# Select background and test sets
train_features = torch.tensor(features[:10000], dtype=torch.float32)
test_features = torch.tensor(features[10000:10100], dtype=torch.float32)

# Create explainer
shap_explainer = Shap(
    model=model,
    background_tensor=train_features[:200],  # Use 200 background samples
    test_tensor=test_features,
    device=device
)

# Explain single instance
shap_values = shap_explainer.explain_local(index=0)
print(f"SHAP values shape: {len(shap_values)}")
print(f"Top positive feature: {shap_values.index(max(shap_values))}")
print(f"Top negative feature: {shap_values.index(min(shap_values))}")

# Global importance
global_importance = shap_explainer.explain_global()
top_k = 10
top_features = sorted(range(len(global_importance)), 
                      key=lambda i: global_importance[i], 
                      reverse=True)[:top_k]
print(f"Top {top_k} important features: {top_features}")

LIME¶

class chemxai.explainers.LIME(model, background_tensor, test_tensor, device, mode='regression')

Local Interpretable Model-agnostic Explanations for tabular data. LIME explains predictions by fitting an interpretable linear model locally around the instance of interest.

Parameters:

  • model (torch.nn.Module) – Trained model to explain
  • background_tensor (torch.Tensor) – Training data for establishing feature distributions
  • test_tensor (torch.Tensor) – Test instances to explain
  • device (torch.device) – Computation device
  • mode (str) – Task type: 'regression' or 'classification'. Default: 'regression'

Methods:

explain_local(index, num_features=None)

Generates local explanation by perturbing features and fitting a linear model.

Parameters:

  • index (int) – Index of test instance to explain
  • num_features (int, optional) – Number of features to include in explanation. If None, uses all features. Default: None

Returns: list – Feature importance coefficients from the local linear model. Positive coefficients indicate features that increase the prediction.

Algorithm:

  1. Generate perturbed samples by randomly masking features
  2. Get model predictions for perturbed samples
  3. Weight samples by proximity to original instance
  4. Fit interpretable linear model (e.g., Lasso) on weighted samples
  5. Return linear model coefficients as feature importance

Example:

from chemxai.explainers import LIME

# Create LIME explainer
lime_explainer = LIME(
    model=model,
    background_tensor=train_features,
    test_tensor=test_features,
    device=device,
    mode='regression'
)

# Explain instance with top 20 features
lime_values = lime_explainer.explain_local(index=5, num_features=20)

# Visualize
import matplotlib.pyplot as plt
import numpy as np

top_indices = np.argsort(np.abs(lime_values))[-20:]
plt.barh(range(20), [lime_values[i] for i in top_indices])
plt.xlabel('LIME Coefficient')
plt.ylabel('Feature Index')
plt.title('Top 20 Features by LIME')
plt.show()

Graph Explainers¶

GNNExplain¶

class chemxai.explainers.GNNExplain(model, device, data, epochs, mode='regression', task_level='graph', return_type='raw')

Explains GNN predictions by learning an edge mask and node feature mask that maximize mutual information with the prediction. Based on the paper "GNNExplainer: Generating Explanations for Graph Neural Networks" (NeurIPS 2019).

Parameters:

  • model (torch.nn.Module) – Trained GNN model (e.g., GCN, GAT)
  • device (torch.device) – Computation device
  • data (torch_geometric.data.Data) – Molecular graph dataset
  • epochs (int) – Number of optimization epochs for learning masks (typically 100-300)
  • mode (str) – 'regression' or 'classification'. Default: 'regression'
  • task_level (str) – 'node' for node-level tasks or 'graph' for graph-level tasks. Default: 'graph'
  • return_type (str) – 'raw' for raw mask values or 'probabilities' for sigmoid-transformed values. Default: 'raw'

Methods:

explain(index=None)

Generates explanation by optimizing edge and node masks.

Parameters:

  • index (int, optional) – Graph index to explain (for graph-level tasks) or node index (for node-level tasks). If None, explains the first instance.

Returns: tuple – (node_mask, edge_mask, explanation_object) where:

  • node_mask (numpy.ndarray) – Importance score for each node. Shape: (num_nodes,)
  • edge_mask (numpy.ndarray) – Importance score for each edge. Shape: (num_edges,)
  • explanation_object – Additional explanation details

Optimization Objective:

GNNExplain learns masks by minimizing:

L = -MI(Y, (G_S, X_S)) + α₁‖M_E‖₁ + α₂H(M_E)

where MI is mutual information, G_S is the masked subgraph, X_S are masked features, M_E is the edge mask, and α₁, α₂ are regularization coefficients.

Example:

from chemxai.explainers import GNNExplain
from chemxai.models import GCN
from chemxai.data import graph_datasets

# Load graph dataset
dataset = graph_datasets(dataset_name='qm9')
data = dataset.load_data()

# Train GCN
model = GCN(num_node_features=11, hidden_dim=64)
# ... train model ...

# Create explainer
gnn_explainer = GNNExplain(
    model=model,
    device=device,
    data=data,
    epochs=200,
    mode='regression',
    task_level='graph',
    return_type='raw'
)

# Explain prediction for molecule 0
node_importance, edge_importance, explanation = gnn_explainer.explain(index=0)

# Identify critical atoms and bonds
import numpy as np
threshold = 0.5
critical_atoms = np.where(node_importance > threshold)[0]
critical_bonds = np.where(edge_importance > threshold)[0]

print(f"Critical atoms: {critical_atoms}")
print(f"Critical bonds: {critical_bonds}")

# Visualize with RDKit
from chemxai.plots import k_hop_subgraph
subset, sub_edges, _, _ = k_hop_subgraph(
    node_idx=critical_atoms.tolist(),
    num_hops=1,
    edge_index=data.edge_index
)

NodeGraphLIME¶

class chemxai.explainers.NodeGraphLIME(data, model, device, gpu=False, hop=2, rho=0.1, cached=True)

Node-level LIME for GNNs. Explains node predictions by fitting a linear model on perturbed subgraphs.

Parameters:

  • data (torch_geometric.data.Data) – Graph data
  • model (torch.nn.Module) – Trained GNN
  • device (torch.device) – Computation device
  • gpu (bool) – Enable GPU acceleration. Default: False
  • hop (int) – Number of hops for extracting local subgraph. Default: 2
  • rho (float) – Lasso regression regularization strength. Default: 0.1
  • cached (bool) – Cache model predictions to speed up explanations. Default: True

Methods:

explain(node_index, hops, num_samples, info=False, multiclass=False)

Explains prediction for a specific node.

Parameters:

  • node_index (int) – Target node to explain
  • hops (int) – Subgraph radius (typically 2-3)
  • num_samples (int) – Number of perturbed graphs to generate (typically 50-200)
  • info (bool) – Print explanation info. Default: False
  • multiclass (bool) – Multi-class classification task. Default: False

Returns: list – Feature importance coefficients for node features

Example:

from chemxai.explainers import NodeGraphLIME

node_lime = NodeGraphLIME(
    data=graph_data,
    model=gcn_model,
    device=device,
    gpu=torch.cuda.is_available(),
    hop=2,
    rho=0.1
)

# Explain node 15
coefficients = node_lime.explain(
    node_index=15,
    hops=2,
    num_samples=100,
    info=True
)

print(f"Feature importance: {coefficients}")

GraphShap¶

class chemxai.explainers.GraphShap(data, model, device=None, gpu=False)

Graph-level Shapley values for molecular property prediction.

Parameters:

  • data (torch_geometric.data.Data) – Graph data
  • model (torch.nn.Module) – Trained GNN
  • device (torch.device, optional) – Device (auto-detected if None)
  • gpu (bool) – Use GPU. Default: False

Methods:

explain(num_samples=30, info=True)

Computes graph-level SHAP values.

Parameters:

  • num_samples (int) – Number of coalitions to sample. Default: 30
  • info (bool) – Print progress. Default: True

Returns: list – SHAP values for graph features

Example:

from chemxai.explainers import GraphShap

graph_shap = GraphShap(
    data=molecular_graph,
    model=gcn_model,
    device=device,
    gpu=True
)

shap_values = graph_shap.explain(num_samples=50, info=True)

# Analyze top features
import numpy as np
top_features = np.argsort(np.abs(shap_values))[-10:]
print(f"Top 10 important features: {top_features}")

Method Selection Guide¶

Method Data Type Prediction Level Theoretical Foundation Computation Time
SHAP Tabular Instance & Global Game theory (Shapley values) Slow (O(2^n))
LIME Tabular Instance Local linear approximation Fast (O(n))
GNNExplain Graph Node & Graph Mutual information Medium (requires training)
NodeGraphLIME Graph Node Local linear approximation Medium
NodeGraphShap Graph Node Shapley values Slow
GraphLIME Graph Graph Local linear approximation Fast
GraphShap Graph Graph Shapley values Slow

Usage Guidelines¶

Tabular Explainers¶

  • SHAP: Use when you need theoretically grounded explanations with consistency guarantees. Reduce background set size (50-200 samples) for faster computation.
  • LIME: Use for quick exploratory analysis. Increase num_samples to 1000+ for more stable explanations.
  • Feature selection: SHAP's explain_global() is more reliable than LIME for global importance.

Graph Explainers¶

  • GNNExplain: Best for understanding which atoms and bonds are critical. Train for 100-300 epochs depending on graph complexity.
  • GraphLIME vs GraphShap: Use GraphLIME for speed, GraphShap for theoretical guarantees.
  • Subgraph extraction: For node-level methods, set hops=2-3 to capture local chemistry.
  • Sampling: More samples (100-200) give stable results but increase computation time.

Notes¶

  • All explainers assume the model is already trained and in evaluation mode
  • For classification tasks, explanation values indicate contribution to the predicted class
  • Graph explainers require PyTorch Geometric
  • SHAP and Shapley-based methods provide additive explanations: sum of contributions equals prediction difference from baseline
