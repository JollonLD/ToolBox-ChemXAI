Explainers Module¶

Overview¶

The Explainers Module provides various explainability methods for both tabular and graph-based molecular models.

Tabular Explainers¶

Shap¶

SHAP (SHapley Additive exPlanations) implementation using KernelExplainer.

Methods¶

  • explain_local(index): Generate local explanation for specific instance
  • explain_global(): Generate global feature importance

LIME¶

Local Interpretable Model-agnostic Explanations for tabular data.

Graph Explainers¶

GNN_Explainer¶

PyTorch Geometric's GNNExplainer for identifying important subgraphs.

GraphShap¶

SHAP-based explanation for graph neural networks at graph level.

GraphLIME¶

LIME adaptation for graph-level explanations.

NodeGraphShap¶

Node-level SHAP explanations for molecular graphs.

NodeGraphLIME¶

Node-level LIME explanations for molecular graphs.

Usage Example¶

from chemxai.explainers import Shap, LIME, GNN_Explainer

# Tabular explainer
explainer = Shap(model, train_data, test_data, device)
local_shap = explainer.explain_local(index=0)

# Graph explainer
gnn_exp = GNN_Explainer(model, epochs=200)
explanation = gnn_exp.explain_local(data.x, data.edge_index)
